快速上手

安装 #

发布包由 scripts/release.ps1 生成在 build/release/<version>/ 中，并附带 SHA256SUMS 文件。每个包内含 pail-desktop 和 pail 两个可执行文件、LICENSE 以及 README。

系统 压缩包
Windows Pail-<version>-windows-amd64.zip、Pail-<version>-windows-arm64.zip
Linux Pail-<version>-linux-amd64.tar.gz、Pail-<version>-linux-arm64.tar.gz（含 pail.desktop 和 pail.png）
macOS Pail-<version>-darwin-amd64.zip、Pail-<version>-darwin-arm64.zip（内含 Pail.app）

可执行文件没有代码签名。macOS 应用也没有公证，需要手动放行后才能通过 Gatekeeper。Pail 从未在真实的 macOS 设备上运行过，macOS 压缩包只做了交叉编译。

快速开始 #

  1. 启动 pail-desktop，在侧栏打开账户切换器并添加账户。以自建或第三方服务为例：

    • 端点 https://s3.example.com，区域 us-east-1，填入访问密钥 ID 和私有密钥；
    • 打开路径样式（MinIO 和大多数自建网关需要开启，AWS 保持关闭）；
    • 可选：设置 CDN URL，例如 https://cdn.example.com。

    点击"测试连接"，然后保存。私有密钥会存入系统钥匙串。

  2. 在侧栏选择存储桶并浏览。把文件拖进窗口即可上传；选中对象后点击下载。

  3. 没有凭据时可以先体验：运行 pail-desktop --demo，它连接的是进程内的内存 S3 服务，数据不会离开本机，也不会保存任何内容。

其他参数：--config-dir DIR、--theme system|light|dark、--size WxH、--tool sync|cloudfront|rules|mime|multipart|settings、--version。

命令行 #

pail 与桌面程序共用账户和同步作业：

pail accounts
pail ls s3://my-bucket/photos/ -r
pail cp ./dist s3://my-bucket/site/ -r --conflict newer
pail sync ./photos s3://my-bucket/photos/ --mode new_changed --dry-run
pail presign s3://my-bucket/report.pdf --expires 1h

命令：accounts、buckets、ls、cp、mv、rm、mb、rb、presign、url、versions、restore、sync、vault status。JSON 输出、退出码和加密保险库的用法见 命令行参考（英文）。

从源码构建 #

需要 Go 1.27.1（见 go.mod），不需要 cgo。

go build ./cmd/pail-desktop ./cmd/pail
./scripts/release.ps1 -Version 0.1.0   # PowerShell 7.3+，交叉编译所有目标
go run ./tools/genicons                # 由 assets/brand/pail-icon.svg 重新生成图标

scripts/release.ps1 需要 assets/brand/generated 中已生成的图标。某个目标构建失败时会被跳过，并列在 NOT-BUILT.txt 中。

数据与隐私 #

  • 配置：系统用户配置目录下的 Pail 文件夹（Windows 为 %AppData%\Pail，Linux 为 ~/.config/Pail，macOS 为 ~/Library/Application Support/Pail），或 --config-dir 指定的路径。里面有设置、账户文件、同步作业、上传规则和秘密引用的名称。如果存在旧名称留下的 openS3 文件夹，会在首次启动时自动迁移一次。
  • 秘密：私有访问密钥、会话令牌和被引用的密码保存在系统钥匙串（Windows 凭据管理器、macOS 钥匙串、Linux 的 Secret Service），服务名为 Pail；也可以选择加密保险库 vault.json（设置 > 安全，适合没有钥匙串的环境）。访问密钥 ID 不是秘密，保存在账户文件中。
  • 日志：默认关闭。开启后，脱敏后的日志写入配置目录下的 logs/pail.log。URL 查询串、Authorization 头、签名和已知的秘密值都会被移除；手动输入的密码只能按标签识别，分享日志前请先检查。
  • 网络：Pail 只访问你配置的账户所对应的端点，没有遥测，也不检查更新。

平台状态 #

已在 Windows 和 Linux（WSLg）上测试。macOS 版本只做了交叉编译，从未在真实设备上运行。目前用过的真实服务端：MinIO（两个版本）和 Cloudflare 后面的自建 VersityGW。AWS 本身，包括 STS 和 CloudFront，尚未测试。各功能的验证结果见 docs/status.md，与 CS Browser Pro 的对照见 docs/feature-matrix.md。
