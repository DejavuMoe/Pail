A desktop client for S3‑compatible storage

Browse buckets, transfer files, and manage object versions, bucket settings and share links. Free and open source, for Windows, macOS and Linux.

Features

Uploads and downloads

Transfer files, folders or whole buckets, or drag files into the window. Uploads and downloads have separate queues with progress, speed, cancel and retry. Large files are uploaded in parts with checksums, and a download is moved into place only after it has been verified.

List every version of an object, download older versions, restore one or undo a delete, and permanently remove only the versions you select.

  • Accounts

    Access keys, AWS profiles, the default credential chain, AssumeRole or anonymous access. For other services, set the endpoint, region and path-style addressing, and test the connection before saving.

  • Bucket settings

    Edit 14 bucket settings, among them versioning, encryption, policy, CORS, lifecycle and replication, as a form or as JSON.

  • Object properties

    Change headers, metadata, tags, ACL, storage class and server-side encryption for one object or a selection. Properties you leave alone are kept.

  • Sync jobs

    Save jobs that upload, download or mirror a folder. Compare by size and time, size or checksum, exclude files by pattern, and review the plan before it runs.

  • Presigned and CDN links

    Create presigned GET or PUT links with an expiry, for one object or many. With a CDN domain set on the account, copy the CDN link as soon as an upload finishes.

  • Upload rules

    Match by bucket and key pattern to set headers, storage class and encryption on upload, or compress files with GZIP, ZIP or AES-256 ZIP.

Privacy

Pail has no telemetry and does not check for updates.

  • Only your endpoints

    Pail connects only to the storage endpoints of the accounts you add.

  • Keychain or encrypted vault

    Secret keys go to Windows Credential Manager, macOS Keychain or the Linux Secret Service. Without a keychain, use the optional vault, encrypted with Argon2id and XChaCha20-Poly1305.

  • Logs off by default

    The diagnostic log is off until you turn it on. Signatures, Authorization headers, URL query strings and known secrets are removed before anything is written.

  • Scope before you confirm

    Destructive actions list what they will affect before they run. To delete a bucket, you type its name.
