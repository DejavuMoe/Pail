更新日志

本项目所有值得注意的变更都记录在此文件中。格式遵循 Keep a Changelog。

未发布 #

Pail 的首个版本。各功能的验证情况记录在 docs/status.md。

新增 #

  • 桌面应用（pail-desktop，Go + mygo，支持 Windows、Linux 和 macOS）：带账户切换器和存储桶列表的侧栏、面包屑、虚拟化的可排序多选对象表（自动分页）、搜索、平铺视图、检查器、传输面板、状态栏、命令面板（Ctrl/⌘+K）、右键菜单和快捷键、亮色与暗色主题、English 与 简体中文，以及基于内存 S3 服务的 --demo 模式。
  • 账户：账户数量不限，支持 AWS 与 S3 兼容服务（自定义端点、区域、路径样式、访问密钥、AWS profile、默认凭据链、匿名、AssumeRole）；连接测试；按账户设置校验和模式。
  • 浏览与预览：存储桶和文件夹导航，JSON、CSV、XML、文本、图片和十六进制预览，复制对象键、URI、URL 和预签名 URL。
  • 传输：上传和下载文件、文件夹、版本与整个存储桶，支持拖放；上传、下载、其他三类独立队列，并发上限可配置，可取消和重试；五种冲突策略；分片传输；仅创建的条件写入，对不支持它的服务商提供回退方案；下载在校验后以原子方式发布。
  • 对象管理：复制、移动和重命名（同一存储桶内及跨存储桶）；批量删除并给出逐项结果；编辑 headers、元数据、标签、ACL、存储类别和服务端加密（SSE-S3、SSE-KMS、SSE-C），事后复核；MIME 类型表。
  • 版本：列出版本和删除标记，恢复某个版本或已删除的键，下载并永久删除多个版本。
  • 存储桶：创建、删除和清空；复制、移动或下载整个存储桶；14 项存储桶设置，可用表单或 JSON 编辑；列出并中止未完成的分片上传。
  • 同步作业：上传、下载和镜像，带预览、三种比较方式和排除 glob；执行时逐项复核已预览的动作；本地删除进入系统回收站。
  • 上传规则：headers、存储类别、加密和压缩（GZIP、ZIP、带压缩级别的 AES-256 ZIP）；下载时解码。
  • 每个账户的 CDN 域名（基础 URL 或 {bucket}/{key} 模板，可选存储桶列表）、预签名 URL 对话框、CloudFront distribution 与失效（AWS 账户）。
  • 命令行（pail）：accounts、buckets、ls、cp、mv、rm、mb、rb、presign、url、versions、restore、sync、vault status；JSON 输出和稳定的退出码；与应用共用账户和同步作业。见 命令行参考。
  • 安全：机密保存在系统钥匙串或可选的加密保险库（Argon2id、XChaCha20-Poly1305）中，支持空闲自动锁定；需主动开启的脱敏诊断日志；每个破坏性或批量操作都会显示范围并要求确认。
  • 与 openS3 的兼容：已有的 openS3 配置文件夹和钥匙串条目会自动迁移；仍可读取旧版保险库和 opens3-* 对象元数据。
  • 工具链：internal/s3test 内存 S3 服务；MinIO 集成测试套件（scripts/test-integration.ps1）；限定前缀的外部端点测试套件（scripts/test-external.ps1，PAIL_EXT_*）；发布脚本，生成 Windows、Linux 和 macOS（amd64、arm64）压缩包及 SHA256SUMS；图标生成器（go run ./tools/genicons）。

安全 #

  • 机密绝不写入配置文件；它们保存在系统钥匙串或加密保险库中。
  • 日志会对 URL 查询串、Authorization 头、签名和已知的机密值脱敏。
  • 自定义端点默认使用"仅在需要时"校验和模式；结果未知的请求绝不重放。

已知限制 #

  • 未在真实 AWS 上测试（STS AssumeRole 和 CloudFront 只在 httptest 上测试）。已测试的真实服务端：MinIO（两个版本）和 Cloudflare 后面的自建 VersityGW。
  • macOS 和 arm64 构建只做了交叉编译，从未在真实硬件上运行过；macOS 应用未签名、未公证。
  • 在 Cloudflare 后面，gzip 编码的对象会被代理解压，因此它们的下载会被拒绝（大小不一致）；不会写入任何错误内容。
  • 未验证：VersityGW 上的版本控制（该服务上已禁用）；SSE-S3、SSE-KMS 和 SSE-C 的成功路径；通过就地重写处理大于 5 GiB 的对象；本地镜像删除进入真实的系统回收站。
  • size_time 同步可能漏掉大小相同的修改；对没有 pail-sha256 元数据的对象，校验和同步会重复传输。
  • 在重命名冲突策略下，只写账户无法检测因重放而产生的 412；大小写冲突的键的编号在多次扫描之间不会被记住。
  • 手动输入的 ZIP 密码和 SSE-C 密钥只能按标签或字段名从日志中脱敏。
  • 来自应用层和命令行的任务标题未本地化。
  • 右键弹出菜单未做视觉评审；对象列表表头无法与设计规范完全一致（mygo 的限制）。
