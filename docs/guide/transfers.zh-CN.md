# 传输

上传、下载、复制和移动都以任务的形式在传输面板中运行，可以在那里查看进度、暂停任务、重试失败的任务。本页还介绍目标已存在时怎样处理、大文件怎样分段传输，以及下载怎样校验。

## 上传

### 文件和文件夹

打开存储桶中的某个文件夹，然后在工具栏中选择 **上传**：

- **上传文件…**：选择一个或多个文件；
- **上传文件夹…**：选择一个文件夹，把它连同其中的所有内容上传到当前文件夹。

托盘图标的菜单里也有 **上传文件…**。

### 拖放

把文件或文件夹从文件管理器拖进对象表格。拖动时，表格会提示上传位置，例如“松开即可上传到 my-bucket/photos/”。松开鼠标即上传到当前打开的文件夹。

把对象表格中的行拖到表格里的某个文件夹上，是移动这些对象，见[复制与移动](#copy-and-move)。

账户设置了 CDN URL 时，上传完成的消息中会提供 **复制 CDN 链接**。CDN URL 的说明见[链接](links.zh-CN.md)。

## 下载

### 对象和文件夹

选中对象或文件夹，选择 **下载**。下载文件夹时会包含它下面的所有内容。

Pail 把文件保存到 **设置 › 下载 › 默认下载文件夹**。这一项为空（**每次询问**）时，每次下载都会询问保存位置。

被上传规则压缩过的对象，下载时会重新解码。

### 版本和整个存储桶

- 对象的旧版本在检查器的 **版本** 标签页中下载，见[版本](versions.zh-CN.md)。
- 整个存储桶用侧栏中存储桶菜单里的 **下载存储桶…** 下载，见[存储桶](buckets.zh-CN.md)。账户为存储桶指定了文件夹时，只下载该文件夹。

### 下载怎样校验

Pail 先把下载内容写入临时文件，校验通过后才把它改成最终的文件名。已有的同名文件也只在这时被替换，所以下载失败或取消时，原来的文件保持不变。

- 下载大小与服务端报告的大小不一致时，Pail 拒绝这次下载，不写出任何文件。经过会解压 gzip 响应的代理时就会出现这种情况，因为代理改变了 gzip 编码对象的大小。
- 有些服务端（例如部分 NAS 设备）不支持只请求文件的一部分。这时 Pail 改用单个连接下载该文件。

## 复制与移动

### 同一账户内

选中对象或文件夹，选择 **复制** 或 **剪切**，打开目标文件夹，再选择 **粘贴**。目标可以是同一账户中的另一个文件夹或另一个存储桶。

- 把选中的行拖到某个文件夹上会立即移动它们，效果与 **剪切** 加 **粘贴** 相同。
- **重命名** 修改一个对象或文件夹的名称，见[对象属性](objects.zh-CN.md#rename)。
- 移动时先复制每个对象，校验副本后才删除源对象。如果目标位置已有内容相同、但标头、元数据、存储类别或标签不同的对象，源对象会保留。

要复制或移动整个存储桶的内容，使用存储桶菜单中的 **复制内容到…** 或 **移动内容到…**，见[存储桶](buckets.zh-CN.md)。

### 跨账户

在一个账户中复制或剪切对象，在侧栏切换到另一个账户，打开那里的某个文件夹，再选择 **粘贴**。不同服务商之间也可以这样做。

对象会经过你的电脑传输，标头、元数据、存储类别和标签一并带过去。移动时，副本校验通过后才删除源对象。

命令行只能在同一账户内复制和移动。

## 目标已存在时

**设置 › 传输 › 文件已存在时** 决定上传、下载或粘贴遇到同名项时怎样处理。它也是 **复制内容到…** 和 **移动内容到…** 的默认值，这两个对话框里可以为本次操作另选。

| 策略 | 处理方式 |
| --- | --- |
| **两者都保留（重命名）** | 新项使用带编号的名称，例如 `report (1).pdf`，不替换任何内容。这是默认设置。 |
| **跳过已存在项** | 保留已有项，跳过新项。 |
| **覆盖** | 始终替换已有项。 |
| **较新时覆盖** | 只有新项的修改时间更晚时才替换。 |
| **大小不同时覆盖** | 只有大小不同时才替换。 |

被跳过的项记为跳过，不算作已上传或已下载。

## 传输面板

开始第一个传输后，窗口底部会出现传输条。点击状态栏中的上传或下载计数可以打开传输面板，**显示或隐藏传输面板** 也可以。

面板有三个标签页，最新的任务排在最前：

| 标签页 | 内容 |
| --- | --- |
| **进行中** | 排队中、正在运行和已暂停的任务，显示进度、已传输字节和速度。 |
| **已完成** | 已完成的任务及其大小。 |
| **失败** | 失败和已取消的任务，附原因。 |

**清除已结束项** 从列表中移除已完成和失败的任务。

一次上传或下载很多文件时，它们属于同一个批次。批次结束时，消息会说明成功和失败的数量，例如“上传完成，部分出错：成功 98 个，失败 2 个”。

### 队列与并发数

上传、下载和其他任务（例如复制、移动或删除对象）分别排队。**设置 › 传输** 决定同时运行的数量：

| 设置 | 含义 |
| --- | --- |
| **并发上传数** | 同时运行的上传任务数，1 到 64。 |
| **并发下载数** | 同时运行的下载任务数，1 到 64。 |
| **其他任务并发数** | 复制、移动、删除等其他任务的同时运行数，1 到 64。 |
| **单任务并发数** | 一个批量任务内同时处理的对象数，1 到 64。 |

其余任务在队列中等待。调低并发数不会中断正在运行的任务。

### 暂停、继续、取消与重试

| 按钮 | 作用 |
| --- | --- |
| **暂停** | 暂停一个上传或下载，或整个批次。 |
| **继续** | 继续已暂停的任务。 |
| **全部暂停** | 暂停所有正在运行和排队的上传与下载。 |
| **全部继续** | 继续所有已暂停的任务。 |
| **取消** | 停止任务。 |
| **重试** | 重新运行失败或已取消的任务。 |

移动或重命名时，如果复制成功但源对象没能删除，重试会把这次移动完成。

### 重启之后

退出 Pail 时仍在排队、运行或已暂停的传输，下次启动时以暂停状态恢复，并有消息说明数量。选择 **继续** 或 **全部继续** 即可接着传输。同步任务的运行不会保存。

> 已暂停的文件继续时会从头开始传输，重启后恢复的也一样。

显示托盘图标时，关闭窗口后 Pail 仍在运行，传输会继续完成，见[托盘图标](browse.zh-CN.md#tray-icon)。

## 限速

**设置 › 传输** 中有 **上传限速** 和 **下载限速**，单位是 KiB/s，所有账户共用，0 表示不限速。正在进行的传输从下一个分段起按新值限速。

## 大文件与校验和

大文件分段上传和下载。**设置 › 传输 › 分段大小** 决定每段的大小，取值 5 到 5120 MiB。分段越大，每个文件的请求越少。

每个账户在账户对话框的 **高级** 中有 **校验和模式**，决定上传时附带、下载时校验的校验和：

| 模式 | 行为 |
| --- | --- |
| **自动** | 默认值。在 AWS 上使用 SDK 的默认行为；对兼容 S3 的服务只发送必需的校验和。 |
| **仅必需时** | 只发送服务要求的校验和。服务拒绝上传时选这一项。 |
| **支持时** | 始终发送校验和。 |

中断的分段上传可能在服务端留下已上传的分段。**工具** 下的 **分段上传** 可以列出并中止这些上传，见[存储桶](buckets.zh-CN.md)。

## 窗口之外的进度

有任务在排队或运行时，Windows 的任务栏按钮和 macOS 的程序坞图标会显示它们的总进度。在 macOS 上，菜单栏图标旁会显示百分比；窗口隐藏时，传输仍保持全速。

## 命令行

`pail cp` 用于上传、下载和在 S3 内复制。`pail mv` 在 S3 内移动：先复制、校验，再删除源对象。

```sh
pail cp ./photos s3://my-bucket/photos/ -r
pail cp s3://my-bucket/photos/ ./downloads -r
pail cp s3://my-bucket/report.pdf s3://backup-bucket/2026/
pail mv s3://my-bucket/inbox/ s3://my-bucket/done/ -r --conflict skip
```

- 上传和 S3 内复制的目标始终是文件夹，源的名称保留在它下面。
- 下载的目标是本地目录，不存在时会创建。
- `--conflict` 可取 `skip`、`overwrite`、`rename`、`newer` 或 `different_size`。省略时使用桌面应用设置中保存的策略。
- `--decode` 取 `gzip`、`zip` 或 `auto`，在下载时解码对象。
- `cp` 不会要求确认，即使用了 `--conflict overwrite`。`mv` 会先显示范围并询问。

传输设置与桌面应用共用：

```sh
pail settings set upload-kibps 2048
pail settings set download-kibps 0
pail settings set part-size-mib 64
pail settings set conflict newer
```

`pail multipart ls` 和 `pail multipart abort` 列出并中止未完成的分段上传。全部参数见[命令行参考](../cli.zh-CN.md#command-details)。
