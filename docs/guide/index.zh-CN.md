# 概览

Pail 由一个桌面应用和一个命令行工具组成，用来管理 Amazon S3 以及 Cloudflare R2、Wasabi、MinIO 等兼容 S3 的存储。它在 Windows、macOS 和 Linux 上运行，以 MIT 许可证免费开源。

## 下载的内容

每个发布压缩包里有两个程序，它们共用同一套账户、已保存的同步任务和设置：

- **桌面应用**（`pail-desktop`）：浏览存储桶，上传和下载，修改对象属性、版本和存储桶设置，运行同步任务和上传规则。macOS 上是 `Pail.app`。
- **命令行工具**（`pail`）：在终端或脚本里完成同样的工作，支持 JSON 输出，退出码固定。见 [命令行参考](../cli.zh-CN.md)。

压缩包里还有许可证；Linux 的压缩包另有 `.desktop` 文件和图标。没有安装程序：解压后直接启动即可，详见 [安装](install.zh-CN.md)。

## 系统

| 系统 | 版本 |
| --- | --- |
| Windows | x64 和 Arm |
| macOS | Apple 芯片和 Intel，需要 macOS 11 或更高版本 |
| Linux | x64 和 Arm |

不提供 32 位版本。

## 支持的服务

Pail 支持 Amazon S3、Cloudflare R2、Wasabi、MinIO、VersityGW，以及其他提供 S3 API 的服务。除 Amazon S3 外，都以兼容 S3 账户的形式添加，填写服务的端点即可。

已知限制见 [更新日志](../../CHANGELOG.zh-CN.md)。

## 主窗口

- **侧栏**：顶部是账户菜单，下面是存储桶列表、工具（**同步任务**、**CloudFront**、**上传规则**、**MIME 类型** 和 **分段上传**），最底部是 **设置**。
- **工具栏**：上传、新建文件夹、计算文件夹大小、刷新，以及作用于所选项目的命令。
- **路径栏**：以面包屑显示当前文件夹，旁边是文件夹筛选框。
- **对象表**：当前文件夹里的文件夹和对象，可排序，每行有复选框。
- **检查器**：按标签页显示所选项目：**概览**、**预览**、**标头**、**标签**、**权限** 和 **版本**。
- **传输面板**：排队、进行中和已暂停的上传与下载，显示进度和速度。
- **状态栏**：项目数量和上一次操作的用时。点击用时打开 **最近操作**。

命令面板（`Ctrl+K`，macOS 上是 `⌘K`）可以按名称查找命令、工具和存储桶。
