# 版本

在启用了版本控制的存储桶中，Pail 会列出对象的每个版本和删除标记，可以下载或恢复旧版本、找回已删除的对象，并且只永久删除你选中的版本。

## 开始之前

只有开启了版本控制的存储桶才有版本。版本控制在**存储桶设置…**中开启；创建存储桶时启用对象锁定，也会开启版本控制，见[存储桶](buckets.zh-CN.md)。

开启版本控制后：

- 用已有的对象键上传对象时，之前的内容保留为旧版本；
- 删除对象时，它的版本都会保留，并在最前面添加一个删除标记；
- 修改标头、元数据、存储类别或加密，会生成一个新版本。

暂停版本控制后，不再保留新的版本，已经保存的版本仍然存在。

## 对象的版本

选中一个对象，打开检查器的**版本**标签页，这里列出该对象的所有版本。每一行显示大小（删除标记显示**删除标记**）、修改时间和版本 ID 的开头部分。当前版本带有**最新**标记。

每一行的按钮：

| 按钮 | 作用 |
| --- | --- |
| **下载此版本** | 把这个版本保存为文件。 |
| **为此版本生成预签名 URL** | 为这个版本生成预签名 URL，见[链接](links.zh-CN.md)。 |
| **恢复此版本** | 让这个版本成为当前版本。最新版本上没有这个按钮。 |
| **永久删除此版本** | 删除这个版本或删除标记。 |

删除标记只有删除按钮。

### 选择多个版本

点击行即可选中，再点一次取消选中。选中版本后，标签页会显示选中的数量，并提供：

- **下载所选版本**：下载选中版本中不是删除标记的那些；
- **永久删除所选版本**。

### 下载版本

下载的版本保存到**设置 › 下载 › 默认下载文件夹**；这一项为空时，Pail 会询问保存位置。它们和其他下载一样在传输面板中运行，见[传输](transfers.zh-CN.md)。

### 恢复版本

**恢复此版本**让旧版本成为当前版本。其他版本都会保留，所以之后还可以再换回来。

### 永久删除版本

**永久删除此版本**和**永久删除所选版本**都会先询问，并显示涉及的对象和版本。部分版本无法删除时，消息会说明失败的数量。

> 版本或删除标记一旦永久删除，就无法找回。

## 已删除的对象

### 显示已删除

路径栏中的**显示已删除**列出当前文件夹中已删除的项，也就是最新版本为删除标记的对象。只有启用了版本控制的存储桶才能使用它；不可用时，把指针停在上面可以看到原因。开启时不能使用**平铺**。

文件夹中没有带删除标记的项时，表格显示**没有已删除的项**。选中某个已删除的项，检查器会显示它的删除时间、大小和对象键。

### 恢复已删除的对象

- 选中已删除的项，选择**恢复**。
- 选择**恢复此文件夹中的全部项**，恢复显示的所有已删除项。

两种方式都会立即恢复，不会询问。恢复后的对象回到删除前的内容，版本历史也会保留。消息会说明恢复了多少项、失败了多少项。

## 命令行

```sh
pail versions s3://my-bucket/photos/
pail versions s3://my-bucket/photos/cat.jpg
pail restore s3://my-bucket/photos/cat.jpg --version-id 3HL4kqtJlcpXroDTDmJ
pail restore s3://my-bucket/photos/cat.jpg --deleted
pail restore s3://my-bucket/photos/ --deleted -r
pail rm s3://my-bucket/photos/cat.jpg --versions
```

| 命令 | 作用 |
| --- | --- |
| `versions` | 列出一层文件夹或一个对象键的版本和删除标记。 |
| `restore --version-id` | 让旧版本成为当前版本。 |
| `restore --deleted` | 恢复最新条目为删除标记的对象键。 |
| `restore --deleted -r` | 恢复前缀下所有这样的对象键。 |
| `rm --versions` | 永久删除一个对象键的所有版本和删除标记。 |

`stat`、`cat`、`tags`、`acl` 和 `presign` 可以用 `--version-id` 指定某个版本：

```sh
pail cat s3://my-bucket/notes.txt --version-id 3HL4kqtJlcpXroDTDmJ > notes-old.txt
```

`restore` 会保留版本历史。`rm --versions` 会先显示范围并要求确认。详见[命令行参考](../cli.zh-CN.md#command-details)。

## 限制

- `pail versions` 只列出一层文件夹，`pail rm --versions` 只接受单个对象键。
- 命令行没有删除某一个指定版本的命令。
- 文件夹大小和 `pail du` 不统计旧版本和删除标记。
