# 对象属性

检查器可以查看和修改对象的标头、元数据、标签和权限，另有两个对话框可以一次更改许多对象的存储类别或服务端加密。本页还介绍对象的重命名、复制、移动和删除，以及怎样从 S3 Glacier 灵活检索和深度归档中取回对象。

> 修改标头、元数据、存储类别或加密，都会原地重写对象。对象的修改时间随之改变；在启用了版本控制的存储桶中，还会生成一个新版本。

## 标头与元数据

### 单个对象

选中一个对象，打开检查器的**标头**标签页。它分为两部分。

**标头**是与对象一起保存、下载时返回的标准 HTTP 标头：

| 标头 | 用途 |
| --- | --- |
| Content-Type | 媒体类型，例如 `text/html` 或 `image/png`。浏览器据此决定怎样打开对象。 |
| Cache-Control | 浏览器和 CDN 可以缓存对象多久，例如 `max-age=3600`。 |
| Content-Disposition | 浏览器是直接显示对象（`inline`），还是把它保存为文件（`attachment`）。 |
| Content-Encoding | `gzip` 或 `br`，仅当保存的内容确实以这种方式压缩时才填写。 |
| Content-Language | 内容的语言，例如 `en` 或 `zh-CN`。 |
| Expires | 缓存从何时起视对象为过期，用 HTTP 日期格式填写。 |

清空某个值即删除该标头。

**用户元数据**保存你自己的键值对，下载时以 `x-amz-meta-*` 标头返回。选择**添加元数据**添加一项。键会以小写保存，所有内容都必须是纯 ASCII 字符，总大小不超过 2 KiB。

选择**保存**写入更改，或选择**还原**放弃更改。在启用了版本控制的存储桶中，标签页会提示**保存会生成新版本。**

### 多个对象

选中多个对象或文件夹，打开**标头**。所做的更改会应用到每个选中的对象，以及选中文件夹中的所有内容。各对象取值不同的字段显示**各不相同**，在你修改之前，每个对象保留自己的值。选择**更新 N 项**应用更改。

## 标签

**标签**标签页编辑单个对象的标签。标签是键值形式的标记，生命周期规则、成本报告和访问策略都可以按标签匹配对象。

- 选择**添加标签**，填写键和值，再选择**保存**。
- 一个对象最多有 10 个标签。以 `aws:` 开头的键是保留的。
- 离开该对象时，未保存的标签修改会被丢弃。

在桌面应用中，标签一次只能编辑一个对象。命令行可以把标签合并到已有标签中，见[命令行](#command-line)。

## 权限

**权限**标签页显示单个对象的 ACL：它的**所有者**和**授权**。**复制所有者 ID** 复制所有者的 ID。

选择一个**预设 ACL** 来替换现有授权：

| 预设 ACL | 授权 |
| --- | --- |
| **私有** | 只有所有者。 |
| **公开读取** | 知道地址的任何人都能读取对象。 |
| **公开读写** | 任何人都能读取和写入对象。 |
| **已认证用户可读** | 任何已认证的 AWS 用户都能读取对象。 |
| **存储桶所有者完全控制** | 存储桶所有者获得完全控制权。 |

选中预设 ACL 后立即生效。两个公开选项会先询问，确认按钮是**设为公开**。与以上都不匹配的授权显示为**自定义授权**。

存储桶关闭了 ACL 时，标签页显示**此存储桶已禁用 ACL**。读不到 ACL 时，Pail 不会修改它。有些兼容 S3 的服务不支持对象 ACL，这时 Pail 会提示服务商不支持该功能。

## 存储类别

选中对象或文件夹，在对象菜单中选择**更改存储类别…**。要更改一个存储桶中的所有对象，在侧栏的存储桶菜单中选择**更改存储类别…**，对话框中的**范围**会显示**整个存储桶**。

| 类别 | S3 名称 |
| --- | --- |
| **标准** | `STANDARD` |
| **标准-不频繁访问** | `STANDARD_IA` |
| **单区-不频繁访问** | `ONEZONE_IA` |
| **智能分层** | `INTELLIGENT_TIERING` |
| **Glacier 即时检索** | `GLACIER_IR` |
| **Glacier 灵活检索** | `GLACIER` |
| **Glacier 深度归档** | `DEEP_ARCHIVE` |
| **低冗余** | `REDUCED_REDUNDANCY` |

服务有自己的类别名称时，选择**其他…**，在**自定义存储类别**中填写名称，只能用大写字母、数字和下划线。

越冷的类别存储越便宜，读取越贵；已归档的对象必须先取回才能读取。更改类别时，每个对象都会复制到自身，所以尚未取回的归档对象和用 SSE-C 加密的对象会逐个失败，其余对象照常更改。

## 服务端加密

选中对象或文件夹，选择**更改加密…**；也可以在存储桶菜单中选择它，作用于整个存储桶。

| 选项 | 含义 |
| --- | --- |
| **无** | 不为对象设置加密。存储桶的默认加密仍可能生效。 |
| SSE-S3 | 由 S3 管理密钥（AES256）。 |
| SSE-KMS | 用 AWS KMS 密钥加密对象。在 **KMS 密钥** 中填写密钥 ID、密钥 ARN 或别名，留空则使用 AWS 托管密钥。 |
| SSE-C | 由你提供密钥。之后只有用这个密钥才能读取对象。 |

SSE-C 要求端点使用 https，因为每个请求都会带上密钥。密钥来自**机密引用**：一个已保存的机密，内容是 base64 编码的 32 字节密钥。机密在**上传规则**页面中用**管理机密…**添加。

更改存储类别或加密后，Pail 会逐个读回对象。服务没有应用更改的对象记为失败。有些兼容 S3 的服务会忽略存储类别和加密。

## 重命名

选中一个对象或文件夹，选择**重命名**（`F2`）。在行内修改名称后按 Enter。名称不能包含 `/`。平铺视图中，以及显示已删除项时，不能重命名。

重命名的做法和移动一样：先把对象复制到新名称，再删除旧对象。

## 复制与移动

**复制**、**剪切**和**粘贴**可以把对象和文件夹复制或移动到另一个文件夹、另一个存储桶或另一个账户。把行拖到某个文件夹上即移动它们。目标已存在时怎样处理，取决于冲突策略。这两部分都在[传输](transfers.zh-CN.md#copy-and-move)中介绍。

任务结束时，消息会说明复制或移动了多少项、跳过了多少项、失败了多少项。

## 删除

选中对象或文件夹，选择**删除**。对话框会显示账户、存储桶、文件夹、前几个对象键，以及将要删除的对象数量和大小，包括选中文件夹中的所有内容。Pail 仍在统计时，数量前会注明“至少”。选择**删除 N 项**确认。

每个对象的结果都会记录下来，消息会说明删除了多少、失败了多少，例如“已删除 120 个对象，2 个失败”。结果未知的删除请求不会重新发送。

在启用了版本控制的存储桶中，删除会保留旧版本并添加一个删除标记，所以对象还能恢复，见[版本](versions.zh-CN.md)。

## 从归档取回

存储类别为 `GLACIER`（S3 Glacier 灵活检索）和 `DEEP_ARCHIVE` 的对象，必须先取回才能读取。取回会生成一份临时副本，在指定天数内可以读取；对象本身仍保持归档状态。

1. 选中对象或文件夹，选择**从归档取回…**。
2. 填写**保留天数**，1 到 365，默认 7。
3. 选择**取回速度**，再选择**取回**。

| 速度 | Glacier 灵活检索 | Glacier 深度归档 |
| --- | --- | --- |
| **加急** | 1–5 分钟 | 不可用 |
| **标准** | 3–5 小时 | 12 小时内 |
| **批量** | 5–12 小时 | 48 小时内 |

取回越快费用越高，服务商对每次取回都会收费。其他类别的对象，以及已经在取回中的对象，会被跳过。

### 查看取回状态

选中对象，查看检查器中的**概览**。取回进行时，**取回状态**一行显示**正在从归档取回**；副本可以读取后，显示“已取回，可读取至”某个日期。

## 命令行

```sh
pail stat s3://my-bucket/report.pdf
pail props set s3://my-bucket/index.html --cache-control "max-age=3600" --content-type text/html
pail props set s3://my-bucket/site/ -r --metadata team=web
pail tags set s3://my-bucket/report.pdf project=alpha --merge
pail acl set s3://my-bucket/report.pdf private
pail storage-class s3://my-bucket/logs/ STANDARD_IA -r
pail archive-restore s3://my-bucket/2025/ -r --days 3 --tier bulk
pail rm s3://my-bucket/tmp/ -r
pail mv s3://my-bucket/draft.txt s3://my-bucket/final/
```

| 命令 | 作用 |
| --- | --- |
| `stat` | 显示大小、时间、ETag、存储类别、标头、元数据、标签和加密方式。 |
| `props` | 读取或修改标头和用户元数据。 |
| `tags` | 读取、替换、合并或清除标签。 |
| `acl` | 显示所有者和授权，或应用预设 ACL。 |
| `storage-class` | 更改存储类别。 |
| `archive-restore` | 把归档对象取回，保留 `--days` 天。 |
| `rm` | 删除对象；加 `-r` 删除文件夹。 |
| `mv` | 在同一账户内移动。 |

`props set`、`storage-class` 和 `archive-restore` 加上 `-r` 时，作用于前缀下的所有对象，会先显示范围并要求确认。`rm` 始终会询问。命令行没有更改加密的命令。全部参数见[命令行参考](../cli.zh-CN.md#objects)。
