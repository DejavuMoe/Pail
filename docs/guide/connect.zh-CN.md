# 连接存储

Pail 里的一个账户就是到一个存储服务的连接：服务在哪里、请求怎样签名、显示哪些存储桶。本页逐项说明账户对话框里的字段，以及 pail 命令中对应的参数。

## 在应用里添加账户

1. 打开侧栏顶部的账户菜单，选择 **添加账户…**。
2. 设置 **服务商**：Amazon S3 选 AWS，其他服务选 **兼容 S3**。
3. 填写 **名称**。账户菜单和命令行都用这个名称指代账户。
4. 兼容 S3 的服务要填写 **端点**、**区域** 和 **路径样式访问**，见 [端点、区域与路径样式](#endpoint-region-and-path-style)。AWS 只需填写 **区域**。
5. 选择 **凭证** 类型并填写对应字段，见 [凭证](#credentials)。
6. 按需填写 **存储桶**、**CDN URL** 和 **CDN 存储桶**，展开 **高级** 查看其他选项。
7. 点击 **测试连接**。显示 **已连接** 后，点击 **保存**。

新账户的默认值：区域 `us-east-1`，**路径样式访问** 开启，凭证为 **访问密钥**，**校验和模式** 为 **自动**。

同一个菜单里还有 **编辑账户…** 和 **从 Pail 移除账户…**。移除账户只会删除本机上保存的连接和它存储的凭证，不会动存储桶和对象。该账户已保存的同步任务会保留，但无法再运行。

## 用链接分享账户

配置链接是一个 `pail://account` 链接，里面是一个账户的设置。在 Pail 中打开它，会填好 **添加账户**。打开链接的人核对设置、补全缺少的字段，再点击 **保存**。表单照常检查各字段，所以不带密钥的链接要填好密钥才能保存。

在账户菜单里选择 **分享配置链接…** 生成链接：

- 需要时修改接收者看到的 **名称**。
- 链接包含服务商、端点、区域、路径样式、凭证类型、AWS 配置文件名称、指定的存储桶、CDN URL 和 CDN 存储桶、AssumeRole 字段、校验和模式和请求者付费。
- 链接不包含账户自己的密钥、代理和 **跳过 TLS 验证**。
- 凭证为 **访问密钥** 时，可以在 **接收者的访问密钥 ID（可选）** 和 **接收者的私有访问密钥（可选）** 里为对方填写密钥，它们会放进链接。拿到链接的人都能使用这些密钥，请只通过私密渠道发送。两项都留空时，由接收者自己填写。
- **复制链接** 复制链接。

使用链接时，直接点击它，或者在账户菜单里选择 **从链接添加账户…** 并粘贴。链接指定了 AWS 配置文件时，在 **配置文件** 里选择你自己的。你填写的密钥会发送到链接里的端点，所以对来源不明的链接，先核对 **端点**。

Pail 每次启动时把自己登记为打开 `pail://` 链接的程序。点击链接没有打开 Pail 时，使用 **从链接添加账户…**。

## 在命令行添加账户

`pail account add` 接受账户名称，其余字段写成参数。它会在终端里以不回显的方式询问私有访问密钥：

```sh
pail account add backup --endpoint https://s3.example.com --region us-east-1 --path-style --access-key-id AKIAEXAMPLE
```

使用 AWS 配置文件（包括通过 `aws login --profile` 创建的会话）的 AWS 账户不需要端点，也不需要私有密钥；省略 `--region` 时会使用配置文件里的区域：

```sh
pail account profiles
pail account add work --profile work
```

- `--secret-stdin` 从标准输入读取一行作为私有密钥，不再提示输入。`--ask-session-token` 还会读取会话令牌。
- 私有密钥和会话令牌不会从参数或环境变量读取，也不会被打印出来。
- `pail account edit NAME --set-secret` 替换已存储的私有密钥；`edit` 的其他参数只修改你给出的字段。
- `pail account show`、`pail account test` 和 `pail account rm` 分别查看、测试和移除账户。

全部参数见 [命令行参考](../cli.zh-CN.md#accounts)。如果机密存放在加密保险库里，命令会先询问主密码，见 [数据与安全](privacy.zh-CN.md)。

## 凭证

| 类型 | 参数值 | Pail 使用什么 |
| --- | --- | --- |
| **访问密钥** | `static` | Pail 保存的访问密钥 ID 和私有访问密钥。 |
| **AWS 配置文件** | `profile` | AWS 配置和凭证文件中的命名配置（包括 `aws login --profile` 和 SSO 会话），例如 `default`。 |
| **默认凭证链** | `default` | 按 AWS SDK 的标准顺序查找：环境变量、共享文件，然后是实例或容器角色。 |
| **匿名访问** | `anonymous` | 不签名的请求，只适用于公开的存储桶。 |

对应的参数是 `--credentials`。给出 `--profile` 时默认为 `profile`，否则默认为 `static`。

如果本机 AWS 配置或凭证文件里已有配置文件，**配置文件** 字段会列出它们及其认证方式和区域，并附带 **其他…** 以手动输入任意名称。`aws login` 会话过期后，在终端重新运行 `aws login --profile NAME` 并在 Pail 中重试即可；Pail 会自动重新读取更新后的 AWS 配置文件。

使用 **访问密钥** 时，**会话令牌（可选）** 只有临时凭证才需要，例如来自 AWS STS 的凭证。会话令牌与私有密钥保存在一起，所以修改令牌时要重新输入私有密钥。编辑账户时，**私有访问密钥** 留空即保留已存储的密钥。

Pail 把私有密钥存进系统钥匙串或加密保险库，不写入配置文件。私有密钥丢失的账户会在侧栏显示 **缺少私有密钥**，点击 **输入私有密钥…** 即可重新输入。

匿名账户无法列出存储桶，需要在 **存储桶** 里填写它们，见 [指定存储桶](#name-the-buckets)。

### AssumeRole

在 **高级** 里，**角色 ARN** 指定一个用上面的凭证代入的 IAM 角色，之后所有请求都以该角色的身份发出。它以 `arn:` 开头，可以配合访问密钥、AWS 配置文件或默认凭证链使用，不能与匿名访问同时使用。

- **外部 ID**：角色的信任策略要求的外部 ID（如果有）。
- **会话名称**：代入角色的会话名称，会显示在 CloudTrail 等 AWS 日志中。留空则自动生成。

在命令行里，对应的参数是 `--role-arn`、`--external-id` 和 `--role-session-name`。

## 端点、区域与路径样式

| 服务 | 服务商 | 端点 | 路径样式 |
| --- | --- | --- | --- |
| Amazon S3 | AWS | 不填 | 不使用 |
| MinIO、VersityGW | 兼容 S3 | 你的服务器，例如 `http://localhost:9000` | 开启 |
| 其他服务 | 兼容 S3 | 服务商提供的地址 | 按服务商的说明 |

- **端点** 是服务的完整地址，以 `http://` 或 `https://` 开头，不含凭证和查询参数。在命令行里，给出 `--endpoint` 即表示兼容 S3 的账户。
- **区域** 是请求签名所用的区域，例如 `us-east-1`。使用 **AWS 配置文件** 或 **默认凭证链** 时，留空则使用配置文件里的区域，未设置时默认为 `us-east-1`。其他情况下除非服务要求特定区域，否则保持默认。
- **路径样式访问** 以“端点/存储桶/对象”的形式访问对象。MinIO 和大多数自建网关需要开启；AWS 保持关闭。命令行参数是 `--path-style`，用 `--path-style=false` 关闭。

### 高级选项

账户对话框的 **高级** 里有 AssumeRole 的字段和下面这些选项：

| 选项 | 参数 | 作用 |
| --- | --- | --- |
| **校验和模式** | `--checksum-mode` | 上传时附带、下载时校验的完整性校验和。 |
| **跳过 TLS 验证** | `--insecure-skip-verify` | 关闭此连接的证书检查。 |
| **请求者付费** | `--requester-pays` | 见 [请求者付费](#requester-pays)。 |
| **代理** | `--proxy` | 见 [单个账户的代理](#proxy-of-one-account)。 |

**校验和模式** 可选 **自动**（`auto`）、**仅必需时**（`when_required`）或 **支持时**（`when_supported`）。**自动** 在 AWS 上使用 SDK 的默认行为，对兼容 S3 的服务只发送必需的校验和。服务拒绝上传时选 **仅必需时**；想始终发送校验和则选 **支持时**。

开启 **跳过 TLS 验证** 后，冒充的服务器可以读取你的数据和凭证。只对自己信任的测试服务器使用，例如使用自签名证书的本地 MinIO。

## 测试连接

账户对话框里的 **测试连接** 会列出一次账户的存储桶；如果指定了存储桶，则列出指定的文件夹。结果显示 **已连接** 或错误，例如访问被拒绝或网络错误。修改任何字段后结果会消失，因为它已不再对应当前的设置。

`pail account add` 在保存前做同样的测试。测试失败时不保存任何内容；`--no-test` 跳过测试直接保存。`pail account test NAME` 测试已保存的账户。

如果测试因为密钥没有列出存储桶的权限而被拒绝，对话框会提示你在 **存储桶** 里填写它们。

## 指定存储桶

有些访问密钥没有列出账户存储桶的权限，或者只能使用某个存储桶里的一个文件夹。对这样的密钥，在 **存储桶** 里填写存储桶名称，用逗号分隔。写成 `bucket/folder/` 可在该文件夹中打开存储桶：

```text
team-data/reports/, public-assets
```

- 侧栏和 `pail buckets` 只显示这些存储桶，每个都在指定的文件夹中打开。
- 路径栏从该文件夹开始。侧栏里的 **下载存储桶…**、**复制内容到…** 等整桶操作只作用于该文件夹。
- 每个存储桶只能指定一个文件夹。
- 服务拒绝列出账户的存储桶时，侧栏会显示 **填写存储桶…**，点击后打开该账户。

在命令行里，每个存储桶写一次 `--bucket`：

```sh
pail account add reports --endpoint https://s3.example.com --access-key-id AKIAEXAMPLE --bucket team-data/reports/ --bucket public-assets
```

**存储桶** 留空时，显示服务列出的全部存储桶。

## 代理

账户有自己的代理时，请求经过它；否则经过 **设置 › 网络** 里的代理。那里选择 **跟随环境变量** 时，由环境变量 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY` 决定。命令行按同样的顺序选择代理。

### 所有账户的代理

在 **设置 › 网络** 里，**代理服务器** 让所有账户的请求经过同一个代理：

1. 选择 **代理协议**：HTTP、HTTPS 或 SOCKS5。选 **跟随环境变量** 则改用环境变量。
2. 填写 **主机名或 IP 地址**（不带 `http://` 和端口）以及 **端口**（1 到 65535）。
3. 按需填写 **用户名（可选）** 和 **密码（可选）**。填写密码时需要同时填写用户名。
4. 点击 **应用**。

密码和其他机密一起存放在钥匙串或加密保险库里。本机地址直接连接。正在运行的传输不会中断。这个设置作用于发往 S3 的请求，对 AWS 账户还包括发往 STS 和 CloudFront 的请求。

这个代理只能在桌面应用里设置；`pail settings` 不能修改它，但 `pail` 会使用它。

### 单个账户的代理

**高级** 里的 **代理** 有三个选项：

- **与设置相同**：使用所有账户共用的代理。
- **不使用代理**：直接连接，忽略设置和环境变量。
- **单独的代理**：填写 **代理地址**，例如 `socks5://127.0.0.1:1080`，协议可以是 `http`、`https` 或 `socks5`。

账户自己的代理不支持用户名和密码；需要认证的代理请在设置中配置。在命令行里，`--proxy` 接受代理地址，`direct` 表示不使用代理，空值表示使用设置中的代理。

### 代理的限制

- Pail 读取环境变量，不读取操作系统的代理设置。
- 不支持需要证书或其他认证方式（如 NTLM）的代理。

## CDN URL

账户可以设置 **CDN URL**，即 CDN 提供对象访问的地址。设置后，对象可以使用 **复制 CDN URL** 和 **打开 CDN URL**，检查器会显示对象的 CDN URL，上传完成的提示里有 **复制 CDN 链接**，`pail url` 也会输出 CDN 链接。

- 基础 URL，例如 `https://cdn.example.com`，生成形如“基础地址/存储桶/对象键”的链接。
- 含 `{bucket}` 和 `{key}` 的模板生成自定义链接。模板用到 `{bucket}` 时也要带上 `{key}`。

```text
https://{bucket}.cdn.example.com/{key}
```

**CDN 存储桶** 把 CDN 链接限制在部分存储桶上，用逗号分隔。留空则此账户的所有存储桶都使用该 CDN URL。地址必须以 `http` 或 `https` 开头，不含凭证、查询参数和片段。

在命令行里，对应的参数是 `--cdn-url` 和 `--cdn-bucket`（每个存储桶写一次）。更多链接相关的内容见 [链接](links.zh-CN.md)。

## 请求者付费

在 **高级** 里开启 **请求者付费**，就可以读写所有者设置了请求者付费的存储桶。之后该账户的每个请求都带上请求者付费标头，这些请求及其传输的数据由你的账户付费。命令行参数是 `--requester-pays`。
