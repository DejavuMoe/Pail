# 浏览与预览

侧栏列出可以打开的账户和存储桶，对象表格显示当前所在的文件夹，右侧的检查器显示所选内容的详情和预览。本页介绍怎样在文件夹之间移动、选择对象，以及不下载就查看对象内容。

## 主窗口

主窗口从左到右依次是：

- **侧栏**：顶部是账户菜单，下面是存储桶列表、**工具**分组，最底部是**设置**；
- 对象表格上方的工具栏和路径栏；
- **检查器**，用**显示或隐藏检查器**打开或关闭。

状态栏位于窗口底部。开始第一个上传或下载后，状态栏上方会出现传输条，见[传输](transfers.zh-CN.md)。

## 侧栏

### 账户

侧栏顶部的账户菜单显示当前账户。打开它可以切换到其他账户，或选择**添加账户…**。添加和编辑账户的方法见[连接](connect.zh-CN.md)。

账户的私有访问密钥丢失时，侧栏显示**缺少私有密钥**。选择**输入私有密钥…**重新填写。

### 存储桶

**存储桶**分组列出当前账户的存储桶，标题旁是存储桶数量。在**筛选存储桶**中输入文字可以缩小列表。只有存储桶的区域与账户的区域不同时，才在行内显示区域；把指针停在存储桶上可以看到它的区域。

- 设置了别名的存储桶，在侧栏、路径栏和命令面板中显示别名。对存储桶执行操作的对话框、链接和命令行仍使用真实名称。别名用**设置别名…**设置，见[存储桶](buckets.zh-CN.md)。
- 账户指定了存储桶时，侧栏只显示这些存储桶，并在指定的文件夹中打开。服务拒绝列出存储桶时，侧栏会提供**填写存储桶…**。
- 命令面板（`Ctrl+K`，macOS 上是 `⌘K`）在**转到存储桶**分组中列出所有存储桶。

点击**工具**标题可以收起这个分组。Pail 会记住你的选择，当前打开的工具仍然可见。**设置**单独占一行，位于工具下方。

## 文件夹与路径栏

S3 并没有真正的文件夹：文件夹是其下所有对象键的共同前缀，例如 `photos/2026/`。Pail 把这些前缀显示为文件夹。

- 双击文件夹，或选中后按 Enter，即可打开。
- 路径栏显示存储桶，以及从存储桶到当前文件夹经过的每一层。点击路径中的某一段即可回到那一层。
- **返回上一级**打开上一级文件夹。
- **刷新**重新列出当前文件夹。

账户为存储桶指定了文件夹时（例如 `my-bucket/reports/`），路径栏从该文件夹开始。

## 对象表格

### 列与排序

表格有**名称**、**大小**、**类型**、**修改时间**和**存储类别**几列。点击列标题按该列排序，再点一次反向排序。

文件夹在**大小**、**修改时间**和**存储类别**列中显示短横线，因为 S3 不为文件夹保存这些信息。计算过文件夹大小后，按**大小**排序时文件夹会按算出的大小排列，见[文件夹大小](#folder-sizes)。

### 大文件夹

对象很多的文件夹会一页一页地列出。表格随着每一页到达而增长，已经显示的行可以直接操作。加载期间状态栏显示**正在加载…**，检查器中的合计附有提示“仍在加载，合计只包含目前已列出的内容”。如果后面某一页加载失败，已加载的行会保留，并显示出错原因。

文件夹的行下方还有空白时，空白处显示**拖放文件到这里上传**。

### 选择对象

| 操作 | 结果 |
| --- | --- |
| 单击 | 选中一行。 |
| `Ctrl` 加单击 | 加选或取消某一行（macOS 上是 `⌘` 加单击）。 |
| `Shift` 加单击 | 选中从上次单击的行到这一行的范围。 |
| 复选框 | 只加选或取消这一行。 |
| 表头复选框 | 选中所有行，或取消选择。 |
| **全选** | 选中所有行（`Ctrl+A`，macOS 上是 `⌘A`）。 |
| `Esc` | 取消选择。 |

也可以拖动来选择：

- 沿复选框列向下拖动，经过的行都会被加选。
- 从行下方的空白处开始拖动，画出矩形框选。画框时按住 `Ctrl`（macOS 上是 `⌘`）会保留已有的选择。
- 单击空白处取消选择。

行填满整个视野时，没有空白处可以开始框选，此时请沿复选框列拖动。

选中两项或更多时，表格下方会出现一条选择栏，显示选中数量和大小，并提供**下载**、**复制**、**剪切**、**删除**和**取消选择**。只选中一项时，改由状态栏显示。

右键单击某一行，菜单只列出适用于所选内容的命令。右键单击行下方的空白处，可以使用**上传文件…**、**新建文件夹**、**刷新**和**全选**。

## 筛选与平铺视图

路径栏中的**筛选文件夹**只显示当前文件夹里名称包含所输入文字的项。按 `Ctrl+F` 可以直接跳到这里。没有匹配项时，表格显示**没有匹配项**；选择**清除筛选**即可恢复所有行。窗口较窄时，这个输入框会收成一个搜索按钮。

**平铺**把当前文件夹下的所有对象（包括子文件夹中的）列成一个列表，此时不显示文件夹。**显示已删除**开启时不能使用平铺。

## 检查器

检查器的内容取决于选择：

- 没有选择：显示当前文件夹的项数、文件夹数、对象数、总大小、区域和账户；
- 一个文件夹：显示它的前缀和 URI，计算后还显示大小；
- 一个对象：显示六个标签页，见下文；
- 多项：显示数量和总大小。

选中的项或当前文件夹中包含文件夹时，合计一栏的名称是**对象总大小**。它只统计对象，因为 S3 不为文件夹保存大小。

单个对象的标签页是**概览**、**标头**、**标签**、**权限**、**版本**和**预览**。标头、标签和权限见[对象属性](objects.zh-CN.md)，版本见[版本](versions.zh-CN.md)。

### 概览

**概览**显示对象的对象键、大小、修改时间、内容类型、ETag、存储类别和加密方式；在启用了版本控制的存储桶中还显示版本 ID。适用时还会显示对象锁定、合法保留，以及从归档取回的状态。字段旁的按钮可以复制对象键、URI、URL、CDN URL 和版本 ID。

### 预览

**预览**读取对象的开头部分并直接显示，不保存文件。

| 类型 | 显示方式 |
| --- | --- |
| JSON | 缩进后的文本。 |
| CSV、TSV | 表格，最多显示前 200 行。 |
| XML、文本 | 文本。Markdown、YAML、日志和源代码文件都按文本显示。 |
| 图片 | PNG、JPEG、GIF 或 WebP，不超过 8 MiB。 |
| 其他 | 前 4 KiB 的十六进制内容。 |

Pail 根据文件扩展名和内容类型判断类型。没有扩展名的文件，如果开头部分读起来是文本，就按文本显示。文本预览最多读取前 1 MiB；对象更长时，预览下方会有提示。

要细看图片，可以放大到 8 倍：

- 在触控板上双指捏合；
- 按住 `Ctrl` 转动鼠标滚轮；
- 使用**放大**和**缩小**按钮。

放大后拖动或滚动可以移动图片。双击图片恢复为适合面板的大小。

## 复制对象键与链接

对象菜单中的**复制链接**包含：

| 命令 | 复制的内容 |
| --- | --- |
| **复制对象键** | 对象键，例如 `photos/cat.jpg`。 |
| **复制 URI** | S3 URI，例如 `s3://my-bucket/photos/cat.jpg`。 |
| **复制 URL** | 对象的公开 S3 地址。 |
| **复制 CDN URL** | 账户设置了 CDN 时，对象在 CDN 上的地址。 |
| **复制预签名 URL…** | 带有效期的预签名 URL，见[链接](links.zh-CN.md)。 |

公开 URL 只有在对象允许匿名读取时才能打开。CDN URL 和预签名 URL 的说明见[链接](links.zh-CN.md)。

同一菜单中的**复制**和**剪切**复制的是对象本身，而不是文字，见[传输](transfers.zh-CN.md#copy-and-move)。

## 新建文件夹

选择**新建文件夹**，填写**文件夹名称**并确认。Pail 会创建一个对象键以 `/` 结尾的空对象，S3 工具会把它显示为文件夹。名称不能包含 `/`。要建多层文件夹，先打开上一层再新建。

## 文件夹大小

S3 不为文件夹保存大小，所以计算之前**大小**一列显示“–”。

- 右键单击一个或多个文件夹，选择**计算大小**。
- 在工具栏中选择**计算文件夹大小**，计算当前显示的所有文件夹。

大小只统计文件夹下的当前对象，不包括旧版本、删除标记和未完成的分段上传。文件夹很大时需要等一段时间，因为要列出它下面的所有对象键。文件夹内容变化后可以再次计算，计算失败也可以重试。选中文件夹时，检查器会显示它的对象数和大小。

## 状态栏与最近操作

状态栏显示当前文件夹的项数；开启筛选时显示“N 项，共 M 项”。只选中一项时也会在这里注明，选中的是对象时还会显示大小。

状态栏还显示上一次成功操作的用时：加载存储桶列表、打开文件夹、上传、下载或删除。上传和下载计数可以打开传输面板。

点击用时打开**最近操作**。每行显示一个操作，以及它是**成功**、**失败**还是**已取消**、用了多长时间、何时结束。**清空**清除列表。这个列表只保存在内存中，退出 Pail 后清空。

**设置 › 诊断**中有两项相关设置：

| 设置 | 作用 |
| --- | --- |
| **保留的最近操作数** | 1 到 1000，默认 100。 |
| **切换账户后保留** | 默认关闭：切换账户时清空列表。开启后保留所有账户的操作，并注明每项所属的账户。 |

命令行没有最近操作列表。

## 托盘图标

Pail 会在 Windows 的通知区域、macOS 的菜单栏和 Linux 的系统托盘中显示图标。关闭窗口只是把窗口隐藏起来，Pail 继续运行，让传输完成。图标菜单包含：

- **打开 Pail**；
- 传输进度；
- **显示传输**；
- **上传文件…**；
- **退出 Pail**。

窗口隐藏时，任务完成的消息以系统通知的形式出现。

**设置 › 外观**中有两个开关：

- **在通知区域显示**（macOS 上是**在菜单栏显示**）可以关闭图标。关闭后，关闭窗口即退出 Pail。
- **空闲时关闭窗口即退出**：没有传输在进行时，关闭窗口会退出 Pail；有传输在进行时，Pail 仍留在托盘中。默认关闭。

再次启动 Pail，或在 macOS 上点击它的程序坞图标，会把已打开的窗口调出来，而不是再开一个。在 Linux 上，图标需要 `libayatana-appindicator3`；没有它时，关闭窗口即退出 Pail。
