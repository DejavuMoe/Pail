# 数据与安全

Pail 把设置保存在本机的一个文件夹里，把机密存进系统钥匙串或加密保险库，只连接你配置的服务。本页列出什么数据存在哪里，以及哪些数据会离开你的电脑。

## 配置文件夹

桌面应用和 pail 命令共用一个配置文件夹，即用户配置目录下的 `Pail` 文件夹：

| 系统 | 文件夹 |
| --- | --- |
| Windows | `%AppData%\Pail` |
| macOS | `~/Library/Application Support/Pail` |
| Linux | `~/.config/Pail` |

两个程序都接受 `--config-dir`，用来改用其他文件夹。

### 文件夹里有什么

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 设置，包括代理（不含代理密码）。 |
| `accounts.json` | 账户：端点、区域、访问密钥 ID 等字段，不含机密。 |
| `sync-jobs.json` | 已保存的同步任务。 |
| `upload-rules.json` | 上传规则。 |
| `mime-types.json` | MIME 类型表。 |
| `transfers.json` | 上次退出时未完成的传输。 |
| `secret-refs.json` | 上传规则所用机密的名称，不含它们的值。 |
| `vault.json` | 加密保险库，只在使用它时存在。 |
| `logs` | 诊断日志，只在开启日志后存在。 |

移除账户会删除它的记录和存储的凭证。状态栏背后的最近操作列表只保存在内存里，退出 Pail 后就清空。

## 机密

机密指能授予访问权限的值：私有访问密钥、会话令牌、代理密码，以及上传规则引用的 ZIP 密码和 SSE-C 密钥。它们不写入配置文件，而是存放在下面两处之一，在 **设置 › 安全** 的 **凭证存储** 里选择：

- **系统钥匙串**（默认），服务名为 `Pail`：Windows 上是 Windows Credential Manager，macOS 上是 macOS Keychain，Linux 上是 Secret Service。
- **加密保险库**：配置文件夹里的一个文件，由你设定的主密码保护。

命令行使用同一个选择。它不会从参数或环境变量读取机密，也不会打印机密，加了 `--json` 也一样。

机密丢失时（例如重置加密保险库之后），账户会在侧栏显示 **缺少私有密钥**。点击 **输入私有密钥…** 重新输入。

## 加密保险库

系统没有钥匙串时（Pail 会提示“本机没有可用的系统钥匙串，可使用加密保险库存放凭证。”），或者你想让机密由单独的主密码保护时，使用加密保险库。保存账户因为没有钥匙串而失败时，账户对话框会提供 **设置加密保险库…**。

加密保险库就是配置文件夹里的 `vault.json`。**设置 › 安全** 里显示它使用的加密算法：Argon2id 和 XChaCha20-Poly1305。

> 主密码忘记后无法找回。重置加密保险库会删除其中的所有机密。

### 创建加密保险库

1. 在 **设置 › 安全** 里，把 **凭证存储** 切换为 **加密保险库**。
2. 在 **创建主密码** 对话框里输入两次密码，至少 8 个字符，最多 1024 字节。
3. 点击 **创建加密保险库**。已存储的凭证会移入加密保险库。

命令行里用 `pail vault init` 完成同样的操作。

### 锁定与解锁

- **自动锁定**：在设定的分钟数内未使用已存储的凭证时锁定加密保险库，可选 **从不**、5、15、30 或 60 分钟，默认 15 分钟。有传输正在运行或排队时不会锁定。
- **立即锁定** 马上锁定；**解锁…** 会询问主密码。
- 使用加密保险库时，状态栏会显示一个锁。点击它可以锁定或解锁。

命令行有自己的锁。每次运行都从锁定状态开始，需要机密时询问主密码：在终端里不回显地输入，或者用 `--vault-password-stdin` 从标准输入的第一行读取。使用 AWS 配置文件、默认凭证链或匿名访问的账户不会被询问。详见 [命令行参考](../cli.zh-CN.md#encrypted-vault)。

### 更改主密码或停用加密保险库

- **更改主密码…** 会先询问当前密码，再让你输入两次新密码。命令行：`pail vault passwd`。
- 把 **凭证存储** 切换回 **系统钥匙串**，凭证会移到钥匙串，随后删除加密保险库文件。命令行：`pail vault backend keychain`。

### 忘记主密码

**重置加密保险库…** 会删除加密保险库及其中保存的所有机密。执行前，它会列出需要重新输入私有密钥的账户、将丢失值的机密引用，以及丢失机密的设置（例如代理密码）。输入 `RESET` 确认。之后机密改存到系统钥匙串，你再把缺失的机密重新输入一遍。云端的存储桶和对象不受影响。

命令行里对应的命令是 `pail vault reset`。

## 日志

诊断日志默认关闭。在 **设置 › 诊断** 里开启 **写入诊断日志**，或者运行 `pail settings set log-to-file on`。

- 日志是配置文件夹里的 `logs/pail.log`，最多保留 3 个文件，每个不超过 5 MiB。**打开日志文件夹** 可以查看它们。
- 日志记录错误和任务结果，其中可能出现文件名和存储桶名。
- 私有密钥、会话令牌、密码、签名、Authorization 标头和 URL 查询参数会被替换为 `[REDACTED]`。
- 手动输入的密码只能按标签识别，分享日志前请先检查一遍。

## 网络

除了检查更新（见下文），Pail 只连接你账户的端点。对 AWS 账户，这包括 AssumeRole 用到的 AWS STS 和 CloudFront API。使用 **默认凭证链** 时，AWS SDK 还可能向本机所在的实例或容器查询角色凭证。

请求经由账户自己的代理、**设置 › 网络** 里的代理，或环境变量 `HTTP_PROXY` 和 `HTTPS_PROXY` 发出，见 [代理](connect.zh-CN.md#proxy)。

Pail 没有遥测。

只有在 **设置 › 更新** 里点击 **立即检查**、运行 `pail update`，或在那里选择每天、每周检查时，Pail 才检查更新。检查时从 GitHub 或 pail.download 读取一个写着最新版本的小文件，下载更新要等你点击。这些请求经由 **设置 › 网络** 里的代理发出，不包含你账户的任何信息。

## 剪贴板

预签名 URL 以机密内容的形式写入剪贴板，所以 Windows 剪贴板历史、macOS 通用剪贴板，以及遵守这一标记的剪贴板管理器不会保留它们。
