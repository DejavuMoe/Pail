# 命令面板与快捷键

Pail 的大部分操作都能用键盘完成：命令面板按名称查找任意命令、存储桶或工具，主窗口为常用的文件操作提供快捷键。右键菜单也能用键盘打开。

## 命令面板

在 Windows 和 Linux 上按 Ctrl+K，在 macOS 上按 ⌘K。Ctrl+Shift+P（⌘⇧P）也能打开它，再按一次同样的键即可关闭。命令面板也是 **更多**（⋯）菜单的第一项。

在 **搜索命令、存储桶和工具** 里输入名称的一部分。搜索既匹配当前语言的名称，也匹配命令的英文名称，所以在中文界面里输入 `upload` 也能找到 **上传文件…**。每个结果旁边会显示它所属的分组。

### 列出的内容

命令按以下顺序分组：

| 分组 | 包含 |
| --- | --- |
| **传输** | **上传文件…**、**上传文件夹…** 和 **下载**。 |
| **对象** | 作用于所选对象的操作，例如 **新建文件夹**、**重命名**、**删除** 和各种复制命令。 |
| **导航** | **返回上一级**、**刷新** 和 **搜索**。 |
| **视图** | **显示或隐藏检查器**、**显示或隐藏传输面板**、**主题** 和 **语言**。 |
| **存储桶** | **新建存储桶…** 和 **存储桶设置…**。 |
| **工具** | 侧栏里的工具，例如 **同步任务** 和 **上传规则**。 |
| **应用** | **键盘快捷键**、**文档**、**关于 Pail**、**退出**，以及锁定或解锁加密保险库。 |
| **转到存储桶** | 当前账户的所有存储桶，按名称或别名列出。当前打开的存储桶带勾选标记。 |

暂时无法执行的命令，例如没有选中任何内容时的 **下载**，仍然留在列表里，以较淡的颜色显示在 **当前不可用** 下。

### 主题与语言

**主题** 和 **语言** 各占一行，名称旁边显示当前值。选择其中一项即可看到它的可选值：

- **主题**：**跟随系统**、**浅色** 或 **深色**。
- **语言**：**跟随系统**、English 或简体中文。

当前值带勾选标记。在空的搜索框里按 Backspace，或选择箭头（**返回全部命令**），即可返回。也可以在完整列表里直接输入某个值，例如 `dark`。

### 命令面板中的按键

| 按键 | 作用 |
| --- | --- |
| 上、下 | 在结果之间移动。 |
| Page Up、Page Down | 一次移动八行。 |
| Enter | 执行高亮的命令。 |
| Backspace | 搜索框为空时，从主题或语言的可选值返回。 |
| Esc | 关闭命令面板。 |

## 键盘快捷键

以下快捷键在主窗口中可用。在 macOS 上，⌘ 代替 Ctrl，⌥ 代替 Alt，⇧ 代替 Shift。应用里也有完整列表：在命令面板或 **更多**（⋯）菜单里选择 **键盘快捷键**。

| 命令 | Windows 和 Linux | macOS |
| --- | --- | --- |
| **上传文件…** | Ctrl+U | ⌘U |
| **上传文件夹…** | Ctrl+Shift+U | ⌘⇧U |
| **下载** | Ctrl+D | ⌘D |
| **新建文件夹** | Ctrl+Shift+N | ⌘⇧N |
| **复制** | Ctrl+C | ⌘C |
| **剪切** | Ctrl+X | ⌘X |
| **粘贴** | Ctrl+V | ⌘V |
| **重命名** | F2 | F2 |
| **删除** | Del | Del |
| **全选** | Ctrl+A | ⌘A |
| **返回上一级** | Backspace 或 Alt+Up | Backspace 或 ⌥Up |
| **刷新** | F5 或 Ctrl+R | F5 或 ⌘R |
| **搜索** | Ctrl+F | ⌘F |
| **显示或隐藏检查器** | Ctrl+I | ⌘I |
| **显示或隐藏传输面板** | Ctrl+J | ⌘J |
| **命令面板** | Ctrl+K 或 Ctrl+Shift+P | ⌘K 或 ⌘⇧P |

只有在没有文本框获得焦点时，**复制**、**剪切**、**粘贴** 和 **全选** 才作用于对象。在文本框里，它们照常复制、剪切、粘贴和选择文字。

菜单和命令面板用纯文本显示快捷键，例如 `Ctrl+Shift+U`。

### 选择

| 操作 | 方法 |
| --- | --- |
| 清除选择 | 按 Esc，或单击行下方的空白处。 |
| 选择一个范围 | 按住 Shift 单击范围的最后一行。 |
| 框选 | 从行下方的空白处开始拖动。 |
| 框选时保留已有选择 | 拖动矩形时按住 Ctrl（macOS 上是 ⌘）。 |

选中两项或更多时，表格下方会出现一条选择栏，显示数量和大小，并提供 **下载**、**复制**、**剪切**、**删除** 和 **取消选择**。

## 右键菜单

右键单击对象、文件夹或存储桶即可打开它的菜单。右键单击一个未选中的行时，会先选中它。对象菜单只列出适用于当前选择的项：

- **打开**、**下载** 和 **计算大小**；
- **复制**、**剪切**、**粘贴** 和 **重命名**；
- **恢复**，在开启 **显示已删除** 时出现；
- 存储类别、加密和归档取回；
- **复制链接** 子菜单，包含对象键、URI、URL、CDN URL 和预签名 URL；
- **打开 CDN URL** 和 CloudFront 失效，在适用时出现；
- **删除**，以红色显示。

**上传文件…**、**新建文件夹**、**刷新** 和 **全选** 只在右键单击行下方的空白处时出现。

在 Windows 和 Linux 上，这些菜单绘制在窗口内部，每条命令都显示图标和快捷键。在 macOS 上它们是系统菜单。

### 键盘操作

在 Windows 和 Linux 上，按 Shift+F10 或菜单键，会在当前行下方打开右键菜单，选择不会改变。

| 按键 | 作用 |
| --- | --- |
| 上、下 | 在菜单项之间移动，跳过分隔线和不可用的项。 |
| Home、End | 跳到第一项或最后一项。 |
| 字母键 | 跳到下一个以该字母开头的项。 |
| 右、Enter | 打开子菜单。 |
| 左 | 关闭子菜单。 |
| Enter | 执行高亮的项并关闭菜单。 |
| Esc | 先关闭子菜单，再关闭菜单。焦点回到对象表。 |

同样的按键也适用于上传按钮、账户切换器和 **更多**（⋯）按钮的菜单。

## 更多菜单

**更多**（⋯）按钮里有 **命令面板**、**设置**、**主题** 和 **语言** 子菜单、**键盘快捷键**、**文档**、**关于 Pail** 和 **退出**。
