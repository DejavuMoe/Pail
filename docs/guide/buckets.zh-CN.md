# 存储桶

创建、清空和删除存储桶，复制或移动整个存储桶的内容，编辑 14 项存储桶设置，清理未完成的分段上传。其中大部分操作在命令行里也有对应的命令。

## 存储桶菜单

在侧栏里右键单击存储桶即可打开它的菜单。在 Windows 和 Linux 上，键盘焦点落在存储桶上时，按 Shift+F10 或菜单键也能打开。菜单里有：

- **打开**、**存储桶设置…** 和 **设置别名…**；
- **下载存储桶…**、**复制内容到…** 和 **移动内容到…**；
- **更改存储类别…** 和 **更改加密…**，作用于存储桶里的所有对象；
- **创建 CloudFront 失效…**，只有 AWS 账户才有；
- **清空存储桶…** 和 **删除存储桶…**；
- **复制名称**，复制存储桶的真实名称。

**存储桶设置…** 和 **新建存储桶…** 也可以在命令面板（`Ctrl+K`，macOS 上是 `⌘K`）里找到。

如果账户指定存储桶时带了文件夹，例如 `my-bucket/reports/`，那么 **下载存储桶…**、**复制内容到…** 等整桶操作只作用于这个文件夹。

## 创建存储桶

1. 点击侧栏 **存储桶** 标题旁的 + 按钮（**新建存储桶**），或在命令面板里选择 **新建存储桶…**。
2. 填写 **名称**：3 到 63 个字符，可用 a-z、0-9、句点和连字符。输入时对话框会提示哪里不符合规则。名称创建后无法更改。
3. 选择 **区域**。AWS 账户从列表中选择，其他账户直接输入，例如 `us-east-1`。区域创建后无法更改。
4. 需要时打开 **对象锁定**。它会同时开启版本控制，而且只能在创建存储桶时选择。
5. 点击 **创建**。

## 清空存储桶

**清空存储桶…** 删除存储桶里的所有对象。对话框显示账户和存储桶，并在统计完成后显示对象数量和总大小。

在启用了版本控制的存储桶里，普通删除只会添加删除标记，旧版本仍然保留，存储桶里依然有数据。勾选 **同时删除所有版本和删除标记** 可以把它们一并删除。清空操作无法撤销。

## 删除存储桶

**删除存储桶…** 要求先输入存储桶名称，**删除存储桶** 按钮才可用。只有空的存储桶才能删除；如果存储桶不是空的，对话框会说明原因，并提供 **清空存储桶…** 按钮。删除操作无法撤销。

## 复制、移动或下载全部内容

- **下载存储桶…** 让你选择一个本地文件夹，然后把存储桶里的所有对象下载到其中以存储桶命名的子文件夹。遇到已存在的文件时，按 **设置 › 传输 › 文件已存在时** 的选择处理。
- **复制内容到…** 把所有对象复制到同一账户下的另一个存储桶。选择 **目标存储桶**，可选填 **目标前缀**，例如 `backup/`（留空表示存储桶根目录），再选择 **对象已存在时** 怎么处理。对象在前缀下保留原来的键路径。
- **移动内容到…** 的用法相同，但开始前会再确认一次，点击 **全部移动** 后才开始。每个对象复制完成后即从源存储桶删除，无法撤销。

这些操作作为任务在传输面板中运行。

## 存储桶设置

**存储桶设置…** 打开一个对话框，左侧列出 14 项设置，右侧是编辑区。其中 6 项用简单表单编辑，另外 8 项直接编辑存储服务交换的 JSON。

服务端不提供的设置显示 **此服务商不支持**。密钥没有读取或修改权限的设置，会提示没有权限。

### 用表单编辑的设置

| 设置 | 作用 |
| --- | --- |
| **版本控制** | 对象被覆盖或删除时保留旧版本。从未开启过版本控制的存储桶显示 **启用** 按钮；开启之后，**状态** 可选 **已启用** 或 **已暂停**。暂停后已经保存的版本仍然保留。 |
| **加密** | 新上传对象的默认服务端加密：SSE-S3（AES-256），或 AWS KMS，可另填 **KMS 密钥 ID**。已有对象不变。 |
| **公共访问** | 四个开关：**阻止公共 ACL**、**忽略公共 ACL**、**阻止公共存储桶策略** 和 **限制公共存储桶**。 |
| **对象所有权** | **存储桶所有者强制**、**存储桶所有者优先** 或 **对象写入者**。选择存储桶所有者强制会关闭 ACL。 |
| **请求者付费** | 从存储桶下载的人支付请求和传输费用，而不是存储桶所有者。 |
| **传输加速** | 允许客户端使用存储桶的加速端点，需额外付费。Pail 只切换这项设置，它自己的传输仍走普通端点。 |

修改后点击 **保存**。**移除配置** 在确认后把这项设置恢复为服务商的默认值。

### 用 JSON 编辑的设置

| 设置 | JSON 内容 |
| --- | --- |
| **策略** | 允许或拒绝访问的存储桶策略。按原文发送，由服务端校验。 |
| **CORS** | 规则（`CORSRules`），告诉浏览器哪些网页来源可以用哪些方法访问这个存储桶。 |
| **生命周期** | 规则（`Rules`），到期后删除对象，或把对象转到其他存储类别。 |
| **服务器访问日志** | 存储桶访问日志的投递位置（`LoggingEnabled`）：目标存储桶和前缀。 |
| **标签** | 存储桶本身的标签（`TagSet`），例如用于成本分摊。 |
| **静态网站托管** | 把存储桶作为静态网站提供，设置索引文档和错误文档，或重定向所有请求。 |
| **对象锁定** | 新对象版本默认获得的保留设置，包括模式和期限。这里不能移除。 |
| **复制** | 用 S3 可以代入的角色（`Role`）把新对象复制到另一个存储桶（`Destination`）。两个存储桶都必须开启版本控制。 |

尚未配置的设置显示 **未配置** 和 **配置** 按钮，点击后编辑器里会填入一个起始模板。**验证** 检查文本是否是有效的 JSON；**保存** 会再验证一次，然后发送。

## 未完成的分段上传

未完成的分段上传会把已经上传的分段留在存储桶里，在上传完成或中止之前，服务商按存储量计费。

1. 打开侧栏 **工具** 分组里的 **分段上传**，也可以从命令面板打开，或用 `pail-desktop --tool multipart` 启动应用。
2. 选择 **存储桶**。要缩小范围，输入 **前缀** 后按 Enter。
3. 表格显示每个上传的对象键、**开始时间**、**存储类别**、**发起者** 和 **上传 ID**。**刷新** 重新读取列表。
4. 选中要清理的上传，点击 **中止…**。确认后 Pail 中止这些上传，已上传的分段随之丢弃，无法撤销。

## 存储桶别名

别名是你自己好认的名字，在侧栏、路径栏和命令面板里代替存储桶名称显示。

1. 右键单击存储桶，选择 **设置别名…**。
2. 填写 **别名** 并保存。留空则重新显示存储桶名称。

存储桶本身不会改名。别名只保存在 Pail 的配置里：作用于存储桶的对话框、链接和命令行仍然使用真实名称。别名最多 64 个字符，同一账户里的两个存储桶不能使用相同的别名。

## 命令行

| 命令 | 作用 |
| --- | --- |
| `pail buckets` | 列出存储桶及其区域。 |
| `pail mb` | 创建存储桶，未给出 `--region` 时使用账户的区域。`--object-lock` 同时开启版本控制。 |
| `pail rb` | 确认后删除空的存储桶。 |
| `pail rm -r` | 对 `s3://bucket` 加 `-r`，确认后删除存储桶里的所有对象。 |
| `pail multipart` | `ls` 列出未完成的上传；`abort` 在确认后中止它们。 |
| `pail bucket alias` | 设置、显示或清除别名。 |

```sh
pail mb s3://my-bucket --region eu-central-1 --object-lock
pail rb s3://my-bucket
pail multipart ls s3://my-bucket/uploads/
pail multipart abort s3://my-bucket --older-than 7d
pail bucket alias s3://my-bucket "Photos"
pail bucket alias s3://my-bucket --clear
```

`--older-than` 让 `multipart abort` 只处理开始时间早于给定时长的上传，例如 `36h` 或 `7d`。14 项存储桶设置只能在桌面应用里编辑。参数和确认方式见命令行参考的 [管理](../cli.zh-CN.md#administration) 和 [确认](../cli.zh-CN.md#confirmation)。
