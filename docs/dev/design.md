# Pail 视觉与交互规范

视觉方案名为 "Graphite & Paper"。颜色 token 的唯一来源是 `cmd/pail-desktop/theme.go`，视图文件禁止硬编码颜色。

## 原则

1. **中性色承担界面。** 暖纸色与石墨色构成层次：侧栏 `Sidebar` < 主区 `Background` < 浮起的 `Surface`（输入框、卡片、对话框）。层次靠明度差和 1px hairline 区分，不靠阴影与色块。同一块表面（卡片、对话框、面板）里只用一种中性底色：内嵌的列表、代码、预览用 1px `Border` 描边的"井"（`theme.go` 的 `well`），可编辑的用输入框的 `Surface` 加 `BorderStrong`，不再铺 `Sidebar` 等第二种底色，以免一张卡片被切成两种色调。
2. **颜色是信号，不是装饰。** 强调色只用在五处：选中行（`Selection`）、焦点环（`Focus`）、进度与激活指示（`Accent`）、文件夹图标（`FolderIcon`）、主按钮。危险色只用于破坏性动作和失败状态。其余图标一律单色：`TextMuted`，次要为 `TextSubtle`。
3. **激活态用中性填充。** 侧栏选中项、工具栏开关、分段控件的当前项用 `ActiveFill` 或 `SurfacePressed`，文字用 `Text`、字重 500。不用蓝色胶囊。
4. **字重只用 400 / 500 / 600。** 层次靠字号与灰度，不靠粗体。字号：13 正文、12 次要、11 分组标签、15 标题。
5. **间距基数为 4**，常用 4 / 8 / 12 / 16 / 20 / 24。控件高 28，表格行高 30，圆角 6（控件）、8（面板）、10（对话框）；键帽是 4。这些数值是 `theme.go` 里的常量 `RadiusControl`、`RadiusPopover`、`RadiusDialog`、`RadiusKeycap`；非控件的小形状另有 `RadiusSmall`（4：徽标、复选框、拖放高亮）、`RadiusBar`（2：进度条）、`RadiusAbout`（12：关于图标）。2px 指示线是直角。视图里不写裸数字：`TestNoBareRadiusOutsideTheme` 会拦下 `theme.go` 之外任何 `.Radius(` 后直接跟数字的调用。**嵌套圆角是同心的**：紧贴在圆角容器内的形状，圆角 = 外圆角 − 内缩距离。浮层（菜单、下拉、最近操作）的行内缩 `popoverPad` 4，圆角 `RadiusRow` = 8 − 4 = 4；分段控件的段内缩 1px 边框 + 2px 内边距，圆角 6 − 3 = 3（`TestSegmentedControlMatchesTheControlHeight` 检查）。不需要圆角的元素（面板、列表区、指示线、图标）不加圆角；阴影只用于浮在窗口上的面板（见"浮层"）。
6. **界面里不放解释性段落。** 必要的提示放 Tooltip 或空状态。

## 状态

中性色填充之间的对比只有约 1.2:1，单靠填充无法区分状态。所以**选中、开启、当前这三种状态，至少要用两种线索表达**：

| 控件 | 填充 | 第二线索 |
| --- | --- | --- |
| 分段控件 | 轨道 `Track` 内凹并带 1px `Border`；当前段用 `Raised` | 当前段加 1px `BorderStrong`，文字用 `Text`、字重 600；其余段用 `TextMuted`、字重 500（不加阴影） |
| 侧栏选中项 | `ActiveFill` | 图标用 `Accent`，名称字重 600。不画左侧色条 |
| 存储桶设置导航的当前项 | `ActiveFill` | 名称用 `Text`、字重 600；其余项用 `TextMuted`、字重 400 |
| 工具页列表（同步任务、上传规则）、版本列表的选中行 | `Selection` | `Selection` 是带色相的填充，色相本身就是第二线索（同对象表）；不画左侧色条 |
| 工具栏开关（检查器、传输面板） | `ActiveFill` | 加 1px `BorderStrong` 描边，图标用 `Text` |
| 检查器标签、传输筛选 | 无 | 2px `Accent` 下划线；当前项用 `Text`、字重 600，其余用 `TextMuted` |
| 开关 | 关闭时轨道 `ControlOff`，开启时 `Accent` | 白色圆钮，位置随状态变化 |
| 复选框 | 未选时 `Surface` 底、1.5px `BorderStrong` 边框；选中与部分选中时 `Accent` 填充 | 选中是 `AccentText` 对勾，部分选中是 `AccentText` 横线 |
| 表格选中行 | `Selection` | 对象表行首的复选框勾选；若有焦点行，焦点行另加 1px `Focus` 内描边 |
| 命令面板、下拉选项、菜单的"当前值"（当前主题、语言、账户、已打开的存储桶、选择框当前项） | 无填充 | `Accent` 对勾加字重 600 |
| 命令面板、下拉选项、菜单的"高亮"（键盘光标或鼠标悬停） | `SurfaceHover` | 无：高亮是临时的指向，不是状态；它与"当前值"是两件事，同一行可以同时有两者 |
| 打开着菜单的按钮（上传、账户切换器、`⋯`） | `SurfacePressed` | 菜单本身挂在按钮下方 |

分段控件与同列的输入框、选择框一样高：轨道高 `controlH`（28，含 1px 边框与 2px 内边距），圆角 `RadiusControl`；段高 22，圆角 `RadiusControl` − 内边距（4）。尺寸常量在 `form.go`（`segmentH`、`segmentRadii`），视图里不写裸数字。

悬停只改填充（`SurfaceHover`），不能与选中状态混淆。禁用状态用透明度 0.4，同时不响应悬停。浮层列表里键盘光标与鼠标悬停是同一种外观（见"浮层"）。

## 对比度（`cmd/pail-desktop/theme_test.go` 强制检查）

- 必要文字（正文、字段标签、表头、按钮文字）≥ 4.5:1：使用 `Text` 或 `TextMuted`。**字段标签使用 `TextMuted`、字重 500**，不用 `TextSubtle`，以免标签被看成占位符。
- `TextSubtle` 只用于占位符、计数、分隔符和次要时间，对比度 ≥ 3.5:1。
- 输入框与次要按钮的描边 `BorderStrong` ≥ 1.8:1；开关关闭时的轨道 ≥ 2:1。
- 状态填充 ≥ 1.17:1，并且必须同时有第二线索。
- 复选框的 `Accent` 填充落在已选行的 `Selection` 与悬停行的 `SurfaceHover` 上都 ≥ 3:1；对勾与横线用 `AccentText`，对 `Accent` ≥ 4.5:1。

## 滚动

- mygo 的滚动条浮在内容之上。凡是可滚动区域，**都必须给滚动条留出内边距槽**：内容右侧内边距 ≥ 滚动条宽度 + 6，并用 `ScrollbarInsets` 把滚动条放进这个槽里。滚动条不能盖住输入框、按钮或文字。
- 对话框结构：固定的标题、可滚动的正文、固定的底部按钮。正文可以滚动时，顶部和底部显示 1px `Border` 分隔线；对话框最大高度为窗口高度减 64。在最小窗口 960×600 下，所有控件必须都能操作。
- 列表和面板在最小窗口下不能出现水平溢出；长文本单行截断，并带 Tooltip。
- 例外：放大后的图片预览在固定大小的框里平移，滚动条浮在图片上，不留槽。框里只有图片，没有文字和控件。

## 布局与缩放

- **布局只用当前帧的尺寸。** 宽度由 `c.Size()` 减去已知的侧栏、检查器和分隔条宽度算出（`layout.go` 的 `layoutMetrics`，每帧在 `body` 里算一次），不读 `Element.Bounds()`：它返回上一帧的盒子，拖动缩放时会晚一帧。
- **宽度断点带 ±12 回滞**：工具栏文字（800）、路径栏紧凑（560）、对象表列（752 / 592，含 32px 复选框列）都只在宽度低于"阈值 - 12"时收起，高于"阈值 + 12"时才展开；档位由 `layoutState` 记住。新增断点必须走 `breakpoint`，不得直接比较宽度。
- 侧栏与检查器保持用户给定的宽度，不随窗口自动缩窄。最小窗口 960×600 下靠工具栏图标化、路径栏紧凑和对象表减列保证所有控件可操作。
- 分隔条（mygo `Split`）悬停用 `BorderStrong`、拖动用 `TextSubtle`，不用 `Accent`（超出强调色的五处用途）；经 `app.split` 给 `Split` 一份私有主题副本实现。
- 单行文本不要用 `Grow(n)`：它同时把 basis 设为 0，文本的最小内容宽度为 0，会被冻结成 0 宽，只剩省略号。要让标签占满剩余空间，把它放进 `Grow(1).MinWidth(0)` 的容器，文本自己用 `Shrink(1).MinWidth(0)`（参见 `kvedit.go`、`help.go`）。

## 浮层

所有浮在窗口之上的界面共用一套外观，实现在 `cmd/pail-desktop/overlay.go`，数值来自 `theme.go`。新增浮层必须经 `overlayPanel`，列表型浮层的行必须经 `listRow`，不得自行写圆角、阴影或高亮色。

**面板种类**（`overlayPanel(kind)`）：

| 种类 | 用于 | 圆角 | 底色 | 边缘 |
| --- | --- | --- | --- | --- |
| `overlayDialog` | 对话框、命令面板、存储桶设置 | `RadiusDialog` 10 | `Surface` | 亮色：阴影 `ShadowDialog`（0 12 32，约 18% 黑）；暗色：1px `BorderStrong` |
| `overlayPopover` | 下拉选项、菜单 | `RadiusPopover` 8 | `Surface` | 亮色：阴影 `ShadowPopover`（0 8 24，约 14% 黑）；暗色：1px `BorderStrong` |
| `overlayTip` | Toast | `RadiusPopover` 8 | `Inverse`，文字 `InverseText` | 亮暗都无描边：反色块本身足够醒目 |

- 暗色背景上阴影看不见，所以暗色的阴影 token 是透明的，面板改用 1px `BorderStrong` 描边；亮色不描边，只靠阴影。两种做法由 token 是否透明决定，视图里不判断主题。
- 只有一层面板，不嵌套边框；对话框内部的滚动、分隔线规则见"滚动"。
- Tooltip 取 `Inverse` / `InverseText` 的颜色（`applyTheme` 设置）。mygo v0.6.3 仍没有改写 `Element.Tooltip` 外观的钩子，它的圆角（5）和阴影仍由库内决定，是已知的例外。

**列表行**（`listRow`，命令面板、下拉选项与菜单共用）：

- 高 28（`listRowH`），左右内边距 8，圆角 `RadiusRow` 4（与外面 8 的面板同心，面板内边距 `popoverPad` 4），子项间距 8；从左到右依次是：14px 图标（`TextMuted`）、标签（13px `Text`）、副文字（12px `TextMuted`）、键帽、对勾（14px `Accent`）、子菜单箭头（`chevron-right`，`TextMuted`）。
- **高亮**：键盘光标所在行与鼠标悬停所在行外观相同，都是 `SurfaceHover` 填充，像原生菜单一样；不用蓝色 `Selection`。鼠标移动时光标跟着鼠标，鼠标静止时键盘方向键夺回光标。
- **当前值**：`Accent` 对勾加字重 600（两种线索）。当前值与高亮互不影响，可以出现在同一行。
- **禁用**：透明度 0.4，不响应悬停，不可点击，键盘光标跳过。
- 命令面板：每行显示命令自己的图标；浏览时命令按分组排列，分组标题用 `sectionLabel`，"此处不可用"也是一个分组标题；有搜索词时跨分组排序，分组名作为副文字显示在行内。
- 选项文字单行截断，不换行。

**键帽**（`keycap`）：高 20，左右内边距 4，圆角 `RadiusKeycap` 4，1px `Border` 描边，12px `TextSubtle`；一个按键一个键帽（`Ctrl`、`Shift`、`U` 是三个）。键帽落在高亮行上时，`Border` 与 `SurfaceHover` 太接近，描边升为 `BorderStrong`、文字升为 `TextMuted`。命令面板的 `Esc` 也是键帽。

**分隔线**（`listSeparator`）：1px `Border`，上下各留 4px 外边距，用于列表里的分组之间。

**菜单**（`ctxmenu.go`）：对象表与侧栏存储桶的右键菜单，以及上传、账户切换器、`⋯` 三个按钮的菜单。

- **平台分工**：Windows 与 Linux 在窗口内自绘，`overlayPopover` 加 `listRow`，与命令面板同一套行；macOS 保留系统菜单（平台约定），同一份描述交给 `ui.Menu`。调用处只写一次菜单描述（`menuBuilder`：`Item`、`Command`、`Separator`、`Submenu`，以及 `Icon`、`Checked`、`Disabled`、`Shortcut`），不判断平台。首尾和连续的分隔线自动去掉。
- **内容**（对象表的右键菜单，`commands.go` 的 `contextLayout`）：只列出此刻能执行的命令，不能执行的不显示成灰色（工具栏和命令面板仍然列出它们），所以菜单短、每一项都能用。顺序是：打开、下载、计算大小 | 复制、剪切、粘贴、重命名 | 恢复 | 存储类别、加密 | "复制链接"子菜单（对象键、URI、URL、CDN URL、预签名 URL） | 打开 CDN URL、CloudFront 失效 | 删除。上传文件、新建文件夹、刷新、全选属于文件夹本身，只在没有选中任何行时（在行下方的空白处右键）出现。
- **外观**：宽 200–320，内边距 4；命令项显示命令表里的图标和第一个快捷键（键帽）；同一层只要有一项有图标，其余项留出图标位，文字对齐。当前值是 `Accent` 对勾加字重 600，禁用是透明度 0.4、不响应悬停、键盘跳过。分隔线用 `listSeparator`。打开着菜单的按钮用 `SurfacePressed` 填充。
- **位置**：右键菜单的左上角落在指针处；放不下时翻到指针的另一侧（向上或向左），两侧都放不下时沿该方向移进窗口，离窗口边 4。按钮菜单挂在按钮下方、左对齐，放不下时改为右对齐或翻到上方（mygo `AttachTo`）。比窗口高时面板高度取窗口高度减 8，行在面板内滚动，滚动条放进右侧槽（见"滚动"）。子菜单贴在所在行的右侧、首行对齐，右侧放不下时翻到左侧。
- **打开**：右键（Windows 在松开右键时，Linux 在按下右键时，沿用 mygo 的判断）；焦点在对象表或存储桶上时按 `Shift+F10` 或菜单键，菜单出现在当前行下方并高亮第一项。按钮菜单在单击、`Enter`、`Space` 或 `↓` 时打开。同一时间只有一个菜单。
- **键盘**：`↑` `↓` 循环移动并跳过分隔线和禁用项；`Home` `End`；`Enter` `Space` 执行；`→` 或 `Enter` 打开子菜单并高亮其第一项，`←` 返回；`Esc` 先关子菜单，再关菜单；按字母或数字跳到下一个以它开头的项。键盘与鼠标共用同一种高亮，规则同"列表行"。
- **鼠标**：鼠标移动到哪一行就高亮哪一行；停在有子菜单的行上 150ms 后打开子菜单，停在别的行上 150ms 后关闭已打开的子菜单；单击子菜单行立即打开。
- **关闭**：执行一项时整条菜单链先关闭，动作在下一帧运行，所以动作打开的对话框能拿到焦点；`Esc`、在菜单外按下（左键或右键）、窗口尺寸变化、窗口失去焦点都会关闭菜单。菜单外的按下只关闭菜单，不会传给下面的控件（与 Windows 系统菜单一致）。关闭后焦点回到打开前的控件。
- **无障碍**：面板是 `RoleMenu`，名称是按钮的名字或"对象操作""存储桶 X 的操作"；各项是 `RoleMenuItem`，可勾选的是 `RoleMenuItemCheckBox` 并报告勾选状态，一组中只能选一项的（主题、语言、账户）是 `RoleMenuItemRadio`，外观同样是 `Accent` 对勾加 600 字重，macOS 系统菜单里同样标为单选项，子菜单项报告展开状态，禁用项报告禁用；焦点留在根面板上，用 `ActiveDescendant` 指向当前高亮项。菜单层是模态的：窗口快捷键暂停，读屏只看到菜单。
- **限制**：自绘菜单不能超出窗口边界；文本输入框与可选文字的编辑菜单（剪切、复制、粘贴等）仍是 mygo 提供的系统菜单。

**Toast**：窗口底部居中，`overlayTip`，内边距 8 / 16，13px 文字，动作按钮 13px / 600，悬停时用 `InverseText` 14% 透明度的填充。出入场见"动效"。

## 动效

界面几乎不动：状态变化在发生的那一帧到位。只有两处过渡，都用 `cmd/pail-desktop/motion.go` 里唯一的令牌 `baseAnim`（`durBase` 250ms，曲线 `easeOut` 即 CSS `ease-out`，`CubicBezier(0, 0, 0.58, 1)`）。视图里不写时长、曲线或弹簧；`TestOnlyTheTokenMoves` 拦下 `motion.go` 与进度条之外的任何动画调用。

**用在哪里**：

- **浮层入场**：对话框和它的遮罩、命令面板、下拉、菜单、子菜单、最近操作、Toast 在出现的位置淡入（`fadeIn`），不缩放、不位移、不弹。关闭时在当帧消失，不留残影，下面的界面立即可用。
- **进度条**：填充宽度追向新进度（任务每秒报告约十次，宽度不随每块数据跳动）；颜色变化（失败变 `Danger`）立即生效。

**不动画的**：悬停与按下的填充、选中、侧栏与导航当前项、检查器标签与传输筛选的下划线、开关圆钮与轨道、复选框、传输面板展开与折叠（含第一个任务到来时）、选择条出现与收起、检查器打开、"已保存"、各种计数（不滚动数字）、窗口缩放引起的布局变化、对象表的行与滚动。鼠标滚轮每一格在约 150ms 内缓出滚过是 mygo 的滚动行为（与浏览器一致），不是应用动画。加载指示沿用 mygo 的 `Spinner`；不做呼吸、脉动等循环动画。Tooltip 沿用库内行为。

**交互不等动画**：淡入中的对话框与菜单立即响应点击和键盘。动画结束后窗口不再请求新帧。

**减少动态效果**：系统开启"减少动态效果"时 mygo 只保留透明度的淡变，正是浮层淡入本身，视图不需要另作判断。

**实现约束（mygo v0.5.5 起仍然如此）**：`Transition` 的 `Enter` 只在父元素上一帧已存在时播放，浮层层又会在过渡之后重新布局，所以浮层的淡入用 `AnimatePose`（绘制时生效的姿态）。
## 窗口外观

- **标题栏与应用融为一体**：所有平台都用 `TitleBarStyle: hidden`（macOS 用 `hiddenInset`），并设置 `TitleBarHeight: 44`，让系统窗口按钮与 44px 的工具栏同高。
  - 侧栏从窗口顶边开始，顶部 44px 是账户切换器。macOS 上它左侧让出红绿灯的位置（`c.TitleBar().Left`）。
  - 右侧主区顶部是一条横贯主区的 44px 工具栏，检查器在它下方。工具栏右侧让出系统按钮的位置（`c.TitleBar().Right`）。
  - 工具栏和账户切换器里的空白区域可以拖动窗口，双击可以最大化。
- **外观同步**：应用主题（跟随系统 / 亮 / 暗）同时设置 `mygo.Theme.SetSource`，让系统按钮、原生对话框，以及 macOS 上的系统菜单与应用一致；Windows 与 Linux 的菜单在窗口内自绘，直接用应用主题（见"浮层"的"菜单"）。窗口 `BackgroundColor` 使用 `light-dark(...)`，避免启动时闪色。
- **不用传统菜单栏**：Windows 与 Linux 不调用 `App.SetMenu`。macOS 保留系统菜单栏（这是平台约定），只放标准项和命令表。
  - 所有命令通过三个入口找到：
    1. 工具栏上的按钮；
    2. 右键菜单（外观与行为见"浮层"的"菜单"）；
    3. **命令面板**（`Ctrl/⌘+K`，也可用 `Ctrl/⌘+Shift+P`）：一个搜索框，列出命令表里的全部命令，每行显示图标、快捷键（键帽）和当前是否可用，支持中英文关键字；外观见"浮层"。
  - 工具栏最右侧（系统按钮左边）有一个 `⋯` 菜单按钮，分组列出：命令面板、设置、主题、语言、键盘快捷键、文档、关于 Pail、退出。
- "关于"对话框：图标、版本、许可证与第三方声明（Lucide ISC、Inter OFL），以及项目链接。

## 文案与本地化

- 支持英文和简体中文，默认跟随系统，找不到匹配的语言时回退英文。语言在 设置 → 外观 中选择：跟随系统 / English / 简体中文。
  - 每个用户可见的界面字符串都放进消息目录，不在视图代码里写死。使用 mygo `i18n` 目录：`cmd/pail-desktop/locales/en.json` 是源语言，`zh-Hans.json` 是译文，采用 ICU MessageFormat 复数写法。
- 中文用语统一：

  | Storage class | 存储类别 |
  | Encryption | 加密 |
  | Signed URL | 预签名 URL |
  | Version | 版本 |
  | Delete marker | 删除标记 |
  | Sync | 同步 |
  | Conflict | 冲突 |
  | Endpoint | 端点 |
  | Region | 区域 |
  | Path-style | 路径样式 |
  | Access key | 访问密钥 |
  | Secret key | 私有密钥 |
  | Secret (stored credential: secret key, session token, password) | 机密 |
  | Secret reference | 机密引用 |

## 组件

### 侧栏

- 背景用 `Sidebar`；与主区之间只有 1px `Border`，侧栏内部没有边框。
- 顶部是账户切换器，高 44，左右内边距 16（首字母方块的左缘与下面列表项的图标同在 x=16）：
  - 左侧 24px 圆角方块，`ActiveFill` 底色，内含账户名首字母，12px、字重 600；
  - 中间账户名 13px / 500，下一行 region，11px `TextSubtle`；
  - 右侧 chevron 图标，`TextSubtle`。
  - 整体是一个可点击区域，悬停时 `SurfaceHover`。
  - 账户的 region 只出现在账户名下一行，不在状态栏和存储桶行里重复（桶行只写与它不同的 region，见下）。
- 分组标签 BUCKETS 用 `sectionLabel`，左右内边距 16，上 16、下 6。数量跟在标签后，用 `TextSubtle`。
- 列表项：
  - 高 28，左右外边距 8，内边距 8，圆角 6；
  - 14px 图标用 `TextMuted`，名称 13px 用 `Text`；
  - 存储桶行的 region（11px `TextSubtle`，靠右）**只在与当前账户的 region 不同时显示**：账户的 region 已在顶部的账户切换器里，同一个值不在每一行重复；账户没有设置 region 时，所有行都不显示。行的 Tooltip 始终写"名称 · region"（有别名时见"桶别名"）；
  - 悬停 `SurfaceHover`；
  - 选中项用 `ActiveFill`，名称字重 500，图标换成 `Accent`。
- 桶筛选框高 28：`Surface` 底色、1px `BorderStrong`、圆角 6，占位文字用 `TextSubtle`，左右外边距 8：外框与列表项的填充同一左缘，框内图标与列表项图标同在 x=16。
- TOOLS 分组贴底；与 BUCKETS 之间是弹性空白，不用分隔色块。
- **TOOLS 可折叠**：分组标签是一个按钮，行高 24，左右外边距 8、内边距 8（标签文字仍与列表项的图标对齐），圆角 `RadiusControl`；内容是 `sectionLabel` 加 12px chevron（展开时 `chevron-down`，折叠时 `chevron-right`，`TextSubtle`），悬停 `SurfaceHover`。它是 `RoleButton`，报告 `Expanded`，Tooltip 是"收起工具／展开工具"，单击、`Enter`、`Space` 切换。折叠时隐藏工具行，**但当前打开的工具那一行保留在标题下面**，让它的选中线索（`ActiveFill`、`Accent` 图标、字重 600）继续说明用户在哪里；BUCKETS 列表得到腾出的高度。状态写入 `settings.json` 的 `collapseTools`（缺省即展开，旧设置文件因此保持展开；展开时不写这个键）。行的出现与消失、chevron 的切换都不加动画。

### 工具栏（高 44，`Background`，底部 1px `Border`）

- 按钮一律 ghost 风格：无底色无边框，高 28，左右内边距 8，图标 14px 用 `TextMuted`，标签 13px 用 `Text`；悬停 `SurfaceHover`，按下 `SurfacePressed`；禁用时整体透明度 0.4。
- 分组之间用 16px 高的竖线 `vline`，左右各留 6。
- 右侧依次是检查器开关、传输面板开关、`⋯`：开关仅图标；打开时用 `ActiveFill`，图标用 `Text`。**传输面板开关和 `⋯` 在每个视图里的位置完全相同**：工具页没有检查器，所以检查器开关排在最前，缺席时右边两个不动（`TestRightToolbarGroupKeepsItsPlace`）。
- 浏览页左侧按顺序分三组，组间用竖线：**上传、新建文件夹 | 计算文件夹大小、刷新 | 下载、复制、剪切、粘贴、重命名、删除**。
  - 第三组是"作用于选择或剪贴板"的命令，**没有选择时不显示**：下载、复制、剪切、重命名、删除只在有选择时出现；粘贴只在应用内剪贴板里有东西时出现（与有没有选择无关）；组里一个按钮也没有时，前面的竖线也不画。该组排在最后，出现和消失不会推动其他按钮，不加动画。
  - 显示但此刻不适用的按钮保持禁用外观（透明度 0.4），例如选中两项以上时的重命名。命令仍在命令面板、右键菜单和选择条里，不受影响。
- "计算文件夹大小"（calculator 图标）在刷新按钮左侧，始终只有图标，名称放 Tooltip；为当前显示的所有文件夹计算大小；已有大小的也重新计算，只有全部正在计算时才禁用。右键菜单的"计算大小"同理：已算出、失败的文件夹都可再次计算，因为文件夹的内容可能在 Pail 之外变过。
- 工具页的顶栏：ghost"返回"按钮、竖线，然后是工具的 14px 图标（`TextMuted`）和名称，二者间距 6。名称是当前位置，规格同路径栏最后一段：13px / 600 `Text`，不用 15px 的标题字号，与左侧 13px 的按钮文字等高。
- 文字标签（上传、新建文件夹、下载）只在工具栏宽度够用时显示（断点 800）。断点按最坏情形量出：有选择、剪贴板也有东西，所有按钮都在，语言用最长标签的伪语言 en-XA；`TestToolbarFitsAtItsLabelBreakpointWithEveryButton` 在标签仍显示的最窄宽度检查最后一个按钮没有碰到右侧开关。最小窗口 960×600 下所有平台的工具栏都是纯图标。

### 路径栏（高 40）

- 面包屑：
  - 前面的段 13px，用 `TextMuted`，悬停变 `Text`；
  - 最后一段用 `Text`、字重 600；
  - 分隔符是 chevron-right 12px，`TextSubtle`；
  - 桶段前放 14px 桶图标。
- 右侧搜索框宽 240，样式同桶筛选框；实际宽度为中间栏的 30%，限制在 140–240，窄时让给面包屑。
- 路径栏紧凑（中间栏宽度低于 560，带回滞）时，搜索框收成一个 28×28 的 ghost 图标按钮（`search` 图标，Tooltip 是搜索框的占位文字），面包屑先得到空间。点图标或按 `Ctrl/⌘+F` 展开成正常宽度并获得焦点；有焦点或有文字时保持展开，失去焦点且为空时再收起；在空的搜索框里按 `Esc` 也收起。展开后搜索框不再让给面包屑。

### 对象表

- 背景 `Background`，没有外框。
- 表头 12px、`TextMuted`，无底色，下方 1px `Border`（表头行高与数据行同为 30，见 `tableRowH`）。可排序列的箭头用 `TextSubtle`。
  - **已知例外：表头字重。** 规格是 500，但 mygo v0.7.4 的 `Table` 把表头文字写死为字重 600（`ui/table.go`），应用无法改写；颜色已经是 `TextMuted`。Windows 的中文界面里，微软雅黑 UI 的 600 是真粗体，所以"名称、大小、类型、修改时间、存储类别"看上去比英文表头和检查器标签更重更深。等 mygo 提供表头字重的钩子再改回 500。
  - **列分隔线：静止时不画。** mygo 给每个可调宽的表头单元格在末端画一条 1px、`Border` 色的调宽边，位置带小数，抗锯齿后有的清晰、有的发虚，看上去像"只有几列有线"。对象表建表时把主题的 `Border` 设为透明（`tableThemeEdges`），静止时一条都不画；表头下方的 1px 线由应用自己画（`tableHeaderLine`）。拖动列宽的光标和手势不变，指针停在边上时边以 `Selection` 色出现（mygo 用主题的 `Accent`，而表格里的 `Accent` 是 `Selection`，所以做不到 `BorderStrong`）。工具页的表保持 mygo 的默认边。
- 行高 30，行与行之间不画分隔线。悬停 `SurfaceHover`，选中 `Selection`，选中行文字保持 `Text`。
- 复选框列：
  - 名称列之前固定一列，宽 32，不能拖动或改宽；复选框 16px，水平居中，外观见"状态"。
  - 行内复选框只在悬停行、已选行上显示；选中两项及以上（选择条出现）时，所有行都显示。其余行的复选框透明，但列宽保留，所以名称列不会左右跳动。
  - 单击复选框切换这一行，其他行的选择不变（同 `Ctrl/⌘+单击`）；`Shift+单击` 复选框从上一次的起点选到这一行。单击行的其他位置仍是单选。
  - 行内复选框不接收键盘焦点，焦点留在表格上；读屏看到的是复选框，名称是"选择 <名称>"，勾选状态与行的选中一致。键盘用 `Ctrl+Space`（Windows、Linux）切换当前行。
- 表头全选：复选框列的表头是三态复选框，始终显示。
  - 状态按当前可见的行算（搜索框筛掉的行不算）：一行未选是未选，全部选中是选中，其余是部分选中。
  - 单击时，未选或部分选中会选中全部可见行，选中会清除选择，与 `Ctrl/⌘+A` 一致。名称是"全选"，Tooltip 显示 `Ctrl/⌘+A`。
  - 列表还在加载后续页时也可以点，只选已加载的行；选择条会注明列表仍在加载。
- 拖动选择：
  - 从复选框列按下拖动是刷选：从按下的行到指针所在的行都加入选择，原有选择保留，不会取消已选的行。不画矩形，行直接显示勾选。
  - 从最后一行下方的空白处按下拖动是框选：拉出矩形，矩形纵向碰到的行成为选择（横向位置不影响）；按住 `Ctrl/⌘` 时加入原有选择。矩形用 `Selection` 50% 透明度填充，1px `Accent` 描边，圆角 2。
  - 名称列和数据列保持原样：单击选择，拖动行移动到文件夹，双击打开。
  - 移动 4px 后才算拖动；不到 4px 时按单击处理：复选框列切换这一行，空白处清除选择（按住 `Ctrl/⌘` 时不变）。
  - 拖动时选择、状态栏和选择条即时更新；`Esc` 放弃这次拖动，回到按下前的选择；松开即结束。指针在列表上下边缘 32px 以内或拖出列表时自动滚动，越往外越快，到头停止。
  - 重命名时、右键或中键按下时、按在滚动条槽上时不开始拖动选择。
- 名称列：16px 图标后接 13px `Text`。文件夹图标用 `FolderIcon`，文件图标用 `TextSubtle`。
- 大小、类型、修改时间、存储类别四列用 12px `TextMuted`；大小右对齐。最右一列的文字末端比单元格内边距再多留 `scrollGutter` − 内边距，不贴滚动条槽。
- 列宽按档位保证不横向滚动：窄档（三列）在 960×600、检查器打开时，中间栏约 390 宽，名称列最小 120、大小列 76、修改时间列 128，日期完整显示，右侧留空隙（`objects.go` 的 `visibleColumns`，`layout_test.go` 检查各档的列宽之和）。
- 文件夹行里没有值的格：大小、修改时间、存储类别都显示"–"（12px `TextSubtle`），类型照常写"文件夹"。大小右对齐，其余起点对齐。
- 文件夹的大小格：S3 不存文件夹大小，算出之前显示"–"（`TextSubtle`）。计算中显示 `Spinner` 和已累计的大小；失败显示"失败"（`Danger`），Tooltip 写原因，可重试。算完显示大小，Tooltip 为"N 个对象 · 大小"。检查器里选中已算出的文件夹时显示同样的"大小"一行，否则显示"计算大小"按钮。
- 按大小排序时，文件夹之间按已知大小排序（未知按 0），文件夹仍排在文件之前。
- 焦点在表格上、且没有在重命名时，`Esc` 清除选择。
- 拖放上传：表格区域整体 1.5px `Accent` 描边、圆角 8，填充 `Selection` 的 50% 透明度，中央是 upload 图标加"Drop to upload to <prefix>"。
- 空状态：垂直居中，32px 图标用 `TextSubtle`，标题 13px / 500，副标题 12px `TextMuted`。
- **拖放提示**：普通列表（不在加载、没有筛选词、不是"显示已删除"、没有失败横幅，且账户可以上传）很短、最后一行下方还剩至少 120px 空白时，在这块空白里居中显示一行：14px upload 图标加"拖放文件到这里上传"，12px `TextSubtle`（`dropHint`）。它不拦截指针：点击、空白处的框选和右键菜单照常；真正拖入文件时消失，由上面的拖放上传遮罩接管。是否显示用当前帧的布局算（`dropHintRoom`：窗口高度减状态栏、传输面板、顶栏、路径栏、选择条、表头和各行），不读 `Element.Bounds()`。

### 选择条（高 36，`Background`，顶部 1px `Border`）

- 选中两项及以上时出现在对象表下方、传输面板上方；选择清空或只剩一项时收起。只选一项时，工具栏和检查器已经覆盖它的操作，不出现选择条，单击行也不会让表格高度变化。
- 左侧是汇总：
  - "已选 12 项 · 3.4 MB"，13px / 500 `Text`，数字逐位滚动；大小只计对象，不计文件夹；
  - 含文件夹时接"· 含 2 个文件夹"，12px `TextMuted`；
  - 列表还在加载时接"· 列表仍在加载"，12px `TextSubtle`。
- 中间是 ghost 按钮：下载、复制、剪切、删除，以及 `⋯`（打开与右键菜单相同的菜单）。按钮来自命令表，是否可用、是否显示与工具栏一致；当前后端不支持的命令不显示。
- 右侧是 ghost 按钮"取消选择"，带 `x` 图标。
- 选择条里没有实底按钮。对象表减列时，所有按钮（包括"取消选择"）只显示图标，名称放 Tooltip；汇总放不下时用省略号截断，按钮不缩小。

### 工具页：列表加详情

同步任务、上传规则这类"左侧列表 + 右侧详情"的工具，列表为空时只显示**一个**空状态，居中在整个工具页主体上（列表窄栏与详情区合在一起，不分栏，也没有列表标题栏）：32px 图标 `TextSubtle`，标题 13px / 500 `Text`，一行 12px `TextMuted` 副标题，下面一个次要按钮创建第一项（`form.go` 的 `emptyAction`）。列表非空而没有选中项时，才在详情区显示"未选择…"的空状态。

**列表头**（`paneBar`，高 40，左右内边距 8，间距 2）在所有这类工具里是同一条：第一个是创建动作，ghost 按钮，加号图标加文字标签（`paneCreate`）；其余动作（删除、复制、上移、下移，以及"?"说明）都只有图标，28×28 的 ghost 按钮，名称放 Tooltip 和无障碍名称（`paneIcon`）。同步任务是"＋ 新建 | 删除"，上传规则是"＋ 添加规则、复制、删除 | ?、上移、下移"，两者的高度、内边距和间距相同（`TestToolListHeadersShareOneShape`）。新增这类工具必须用这两个函数，不得另写。

上传规则的编辑器底栏（管理机密、还原、保存）只在编辑某条规则时显示；没有选中规则时整条隐藏，除非草稿里有仍要保存的改动（在列表里关掉了某条规则，或删光了所有规则）或有错误要显示，这时只留还原与保存。底部"测试"栏里存储桶输入框定宽，对象键输入框占满剩余宽度，右缘对齐内容内边距。

### 检查器（宽 320，`Background`，左侧 1px `Border`）

- 顶部标签条高 40，左右内边距 9：第一个 28px 标签里的 14px 图标正好落在正文的 16px 左缘上：
  - 图标按钮 28×28，未激活时图标 `TextMuted`；
  - 激活项的图标与文字都用 `Text`，正下方是 2px `Accent` 指示线（宽同按钮，圆角 1）；
  - 不使用填充胶囊。
- 头部，内边距 16：
  - 24px 图标（`TextMuted`），不加底色块；
  - 名称 14px / 600 单行省略，副标题 12px `TextMuted`。
- 属性列表：
  - 不画格子表，每行为标签（12px、字重 500、`TextMuted`，宽 96；`inspectorLabel`，与"对比度"一节一致，不用 `TextSubtle`）加值（13px `Text`），行距 8；
  - 分组之间留 16 间距，加 hairline 和分组标签；
  - 长值（ETag、Key、URI、URL）独占一行：标签单独一行，值用 12px 等宽字体可换行，右上角放复制按钮 `iconButton`。
- 图片预览：
  - 适配检查器的内容宽度，圆角 `RadiusControl`；下方一行是像素尺寸与当前显示比例（12px `TextSubtle`），右侧是缩小、放大两个 `iconButton`，到达适配宽度或 8 倍时对应按钮禁用。
  - 捏合触控板或按住 Ctrl 滚动滚轮，在指针处缩放；按钮绕框的中心缩放。框保持适配时的大小，缩放不推动下方内容。
  - 放大后拖动（抓手光标）、滚轮或触控板平移；双击回到适配宽度。换一个对象时回到适配宽度。

### 传输面板

- 默认高 168：标题栏 32 加 4 行。最小 96，可折叠。背景 `Background`，顶部 1px `Border`。
- **折叠条（`transfersBar`，高 32）只在任务列表里有任务时显示**。列表里一个任务也没有（没有排队、进行、完成或失败的）且面板没有打开时，整条不渲染，高度为 0，对象表占满这块空间；第一个任务加入时它当帧出现，最后一个任务离开（"清除已完成"之后）且面板收起时当帧消失，都不加动画。折叠条左右内边距 16，与展开后的标题栏同一左缘。工具栏的传输开关、`Ctrl/⌘+J`、命令面板，以及状态栏右侧的上传下载计数（见"状态栏"）在没有任务时照样能打开面板，面板显示各标签自己的空状态。
- 标题栏：
  - "Transfers" 12px / 600；
  - 筛选项是文字标签"Active 3 / Completed 1 / Failed 1"，12px `TextMuted`；当前项用 `Text`，下方 2px `Accent` 指示线；
  - 右侧是"Clear finished"文字按钮和折叠按钮。
- 行高 32，从左到右依次为：
  - 方向图标，14px `TextMuted`；
  - 名称，13px 弹性宽度；
  - 进度条：固定宽 160、高 4、圆角 2，轨道 `Border`，填充 `Accent`，失败时整条为 `Danger`；
  - 字节数：右对齐宽 128，12px `TextMuted`，例如"1.6 GB of 2.4 GB"；
  - 速度与剩余时间：宽 112，12px `TextSubtle`；
  - 取消或重试按钮 `iconButton`。
- 状态图标：完成用 check `Success`，失败用 alert-circle `Danger`，排队中显示"Queued"，`TextSubtle`。
- 任务栏进度（`Window.SetProgressBar`）：有排队或进行中的任务时，Windows 任务栏按钮、macOS Dock 图标、支持 Unity launcher API 的 Linux dock 显示它们合计的进度：按已传字节与总字节，没有字节数时按项目数，都没有时显示不确定进度；以 0.5% 为步长，值不变时不重复设置。没有活动任务时清除。同步在 UI 线程处理后台事件后执行，不依赖窗口绘制。

### 状态栏（高 24，`Sidebar`，顶部 1px `Border`）

- 左右内边距 16，与侧栏内容同一左缘；12px `TextMuted`，各段之间用 `·` 分隔，分隔符为 `TextSubtle`。
- 左侧只说当前列表：项目数（带筛选、加载中的变体），有选择时接"·"和"已选 N 项，大小"。**不写账户名和存储桶 region**：账户在侧栏顶部的账户切换器里，region 在检查器里，状态栏不重复。工具页的左侧为空。
- 右侧传输摘要用 arrow-up / arrow-down 12px 图标加数字，不用 Unicode 箭头字符。它是**一个小按钮**（样式同下面的用时：高 20、左右内边距 6、圆角 `RadiusKeycap`、悬停 `SurfaceHover`、按下 `SurfacePressed`），点击切换传输面板，名称和 Tooltip 取命令表里的"transfers"命令，报告 `Expanded`。没有任务时折叠条不显示，所以这是面板始终可达的入口。
- 右侧、传输摘要左边是最近一次成功操作的用时：timer 12px 图标加时间（"850 ms"、"3.5 s"、"1 m 05 s"、"2 h 07 m"，单位各语言相同，数字逐位滚动）；悬停时说明是哪一次操作（加载存储桶列表、打开文件夹、上传、下载、删除）。它是一个按钮：点击、`Enter` 或 `Space` 打开"最近操作"列表（下一节）。这个值只记用户发起且成功的操作：上传和删除完成后自动刷新的列表不覆盖它；失败和取消的操作不更新它；切换账户清除。列表里有记录、而没有可显示的用时（切换账户后保留了列表，或只有失败的操作）时，只显示 timer 图标。没有任何记录时整个控件不显示。

### 最近操作列表

`cmd/pail-desktop/recentops.go`（界面）与 `optime.go`（记录）。用户发起的每次操作结束时记一条，不论成功、失败还是取消，让人回头看"刚才那次为什么慢"。它不是诊断日志：不记请求细节，不写盘，退出后清空。

- **入口与面板**：点状态栏的用时。`ui.PopoverBase`，`overlayPopover`，宽 400，出现在用时上方，右边缘贴着窗口；点击面板外、再点一次用时或按 `Esc` 关闭，焦点回到用时。打开时用时保持 `SurfacePressed` 并报告 `Expanded`。入场和退场与选择下拉相同（`overlayEnter`、`overlayExit`）。
- **尺寸**：标题行 36，其下 1px `Border`，每行 44，列表上下各 4。总高最大 360 且不超过窗口高度减状态栏与 16；超出时列表滚动，右侧给滚动条留槽（`scrollGutter`）。
- **标题行**："最近操作"13px / 600，后面是条数 12px `TextMuted`，右边是"清空"文字按钮（只清列表，不动状态栏的用时）。列表为空时显示空状态"没有最近的操作"。
- **行**（最新的在最上，不可点击）：左边 14px 状态图标，中间两行，右边两行。
  - 状态图标三种形状，颜色不是唯一线索：成功 `circle-check` `Success`，失败 `circle-alert` `Danger`，已取消 `x` `TextMuted`。
  - 第一行是操作名（加载存储桶、打开文件夹、上传、下载、删除），13px / 500 `Text`。
  - 第二行 12px `TextMuted`，单行省略，悬停显示全文，各段用"·"连接：已取消写"已取消"；失败且没有失败项计数时写"失败"；计数（文件夹的项数，上传下载的文件数，删除的对象数）；失败项数"N 项失败"；失败原因；位置"桶/前缀"，用真实桶名，不用别名；列表里有两个以上账户时最后写账户名。
  - 右边第一行是用时 13px / 500（格式同状态栏；排队中就被取消、从未开始的任务没有用时，显示"—"），第二行是结束时刻 12px `TextMuted`：当天写 `15:04:05`，其他日期写 `01-02 15:04`。
  - 行的无障碍名称是"名称，状态，用时"。
- **记什么**：加载存储桶列表、打开文件夹（最后一页返回时）、上传、下载、删除。一批任务的用时从第一个任务开始到最后一个任务结束。失败：请求出错，或传输与删除有失败项。已取消：用户取消了任务，或文件夹列表在结束前被另一个文件夹或账户取代。上传和删除完成后自动刷新的列表不记。
- **保留**：只在内存里。条数默认 100，设置 › 诊断 里可改，1 到 1000（`settings.json` 的 `recentOps`）；调低后列表立即截到新条数，调高不会找回已丢掉的条目。
- **切换账户**：设置 › 诊断 的"切换账户后保留"（`keepRecentOps`，默认关）。关时切换账户清空列表；开时保留，列表里有多个账户时每行写账户名。两种情况下状态栏的用时都清除。切走账户后才结束的那个账户的操作，在设置关时丢弃。

### 桶别名

桶可以有一个只在本机显示的别名（桶右键菜单"设置别名…"）。侧边栏、路径栏第一段、命令面板、检查器标题和"返回"按钮显示别名；侧边栏项目和路径栏第一段的悬停说明是"别名 · 真实名称"。侧边栏筛选、命令面板同时匹配别名与真实名称。会对桶做操作或让人核对目标的地方一律显示真实名称：删除、清空、复制等对话框、对象 URI、"新建文件夹"的位置、列表失败的提示和传输任务。别名在同一账户内不能重复，最长 64 个字符。

### 设置页的"网络"区

位于"下载"与"安全"之间，只有"代理服务器"。第一行是协议选择框："跟随环境变量"（默认）、HTTP、HTTPS、SOCKS5（协议名各语言相同）。选了协议后展开"主机和端口"（主机名或 IP 地址，端口 96 宽）、"用户名（可选）"、"密码（可选）"。这几项只有合在一起才有意义，所以不像其他设置那样随改随存：有改动时出现"应用"按钮（靠左，不拉满），按下或在字段里按 Enter 才保存；没有改动时按钮不显示。问题在按下"应用"之后才在对应字段下说明（缺主机、主机里带了协议或端口、端口不在 1–65535、密码没有用户名），已保存的值不变；保存失败的原因显示在按钮下，字段保留以便重试。成功后字段回到保存的规范形式，第一行旁短暂显示"已保存"。已存的密码不回显：密码框的占位文字是"已保存，输入新密码可替换"，留空即保留；清空用户名会同时删除密码。选回"跟随环境变量"并应用，会删除代理、用户名和密码。保险库重置对话框把"代理密码"列在"丢失机密的设置"下，重置后设置页顶部提示重新输入。

### 托盘图标

`cmd/pail-desktop/tray.go`。Windows 通知区域、macOS 菜单栏、Linux AppIndicator。默认显示；设置 → 外观 的开关（界面文案 Windows 与 Linux 为"在通知区域显示"，macOS 为"在菜单栏显示"）写入 `settings.json` 的 `hideTrayIcon`，缺省即显示，旧设置文件因此保持显示。图标显示时，"空闲时关闭窗口即退出"（`quitWhenIdle`，缺省关）开启后：没有传输在进行时，关闭窗口直接退出；有传输时仍隐藏到托盘，传输完成后不自动退出。

- **图案**：`assets/brand/pail-tray.svg`，取应用图标的三层渐细地层和圆点，不带底板。macOS 与 Windows 用单色模板图，由系统按菜单栏、任务栏的明暗着色。Linux 用完整彩色应用图标，因为 AppIndicator 面板不会给图片着色。
- **菜单**（所有平台都是系统原生菜单），依次：打开 Pail、传输状态行（"2 个传输 · 25%"或"没有进行中的传输"，不可点）、显示传输、上传文件…、退出 Pail。Tooltip 是"Pail — 状态"。
- **点击**：Windows 左键单击图标打开窗口，右键打开菜单；Linux 单击打开菜单，面板的"激活"（GNOME 为双击）打开窗口；macOS 单击打开菜单，有传输时百分比显示在图标旁。
- **关闭窗口**：图标显示时，关闭窗口只隐藏，Pail 继续运行以完成传输；退出走图标菜单的"退出 Pail"或应用自己的退出命令（⌘Q）。关闭图标开关时，关闭窗口直接退出。桌面不支持托盘（缺少 libayatana-appindicator3 的 Linux）时跳过图标，关闭窗口直接退出。
- **窗口隐藏时**：本来显示 Toast 的消息（如"已上传 3 个文件"）改发系统通知，系统支持时才发；macOS 需要打包后的应用。
- **单实例**：每个用户只运行一个 Pail（`--demo`，仅 `-tags pail_demo` 构建有，与自定义 `--config-dir` 除外）。macOS 程序坞图标和再次启动都把隐藏的窗口带回前台。

### 需要用户判断的地方

只在动作不可撤销、或会删除数据时才多问一句；能撤回的动作，按下按钮就是决定，结果用 Toast 说明。必须问时，问题放在用户本来就在做选择的地方。

- **不再追问**：拖放移动（与剪切、粘贴一致，拖回即可撤回）；"恢复此文件夹中的全部已删除项"（恢复不删除任何东西）；多个对象的标头保存（按钮写明"更新 N 项"，按下即保存）；同步运行且计划里没有删除（预览就在按钮旁边，已经说明会做什么）。
- **仍然确认**：删除对象与版本、删除和清空存储桶、移动存储桶内容、删除账户与机密、中止分段上传、同步计划含删除、移除存储桶配置、把 ACL 改为公开；保险库的密码与重置。
### 按钮总则

只有三种按钮：ghost、次要（描边）、主要或危险（实底）。整个窗口同一时间最多只有一个实底按钮。
