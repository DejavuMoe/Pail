# Pail 视觉与交互规范

视觉方案名为 "Graphite & Paper"。颜色 token 的唯一来源是 `cmd/pail-desktop/theme.go`，视图文件禁止硬编码颜色。

## 原则

1. **中性色承担界面。** 暖纸色与石墨色构成层次：侧栏 `Sidebar` < 主区 `Background` < 浮起的 `Surface`（输入框、卡片、对话框）。层次靠明度差和 1px hairline 区分，不靠阴影与色块。
2. **颜色是信号，不是装饰。** 强调色只用在五处：选中行（`Selection`）、焦点环（`Focus`）、进度与激活指示（`Accent`）、文件夹图标（`FolderIcon`）、主按钮。危险色只用于破坏性动作和失败状态。其余图标一律单色：`TextMuted`，次要为 `TextSubtle`。
3. **激活态用中性填充。** 侧栏选中项、工具栏开关、分段控件的当前项用 `ActiveFill` 或 `SurfacePressed`，文字用 `Text`、字重 500。不用蓝色胶囊。
4. **字重只用 400 / 500 / 600。** 层次靠字号与灰度，不靠粗体。字号：13 正文、12 次要、11 分组标签、15 标题。
5. **间距基数为 4**，常用 4 / 8 / 12 / 16 / 20 / 24。控件高 28，表格行高 30，圆角 6（控件）、8（面板）、10（对话框）；键帽是 4。这些数值是 `theme.go` 里的常量 `RadiusControl`、`RadiusPopover`、`RadiusDialog`、`RadiusKeycap`，视图里不写裸数字。
6. **界面里不放解释性段落。** 必要的提示放 Tooltip 或空状态。

## 状态

中性色填充之间的对比只有约 1.2:1，单靠填充无法区分状态。所以**选中、开启、当前这三种状态，至少要用两种线索表达**：

| 控件 | 填充 | 第二线索 |
| --- | --- | --- |
| 分段控件 | 轨道 `Track` 内凹并带 1px `Border`；当前段用 `Raised` | 当前段加 1px `BorderStrong` 和阴影 `Shadow`，文字用 `Text`、字重 600；其余段用 `TextMuted`、字重 500 |
| 侧栏选中项 | `ActiveFill` | 左侧 2px `Accent` 指示条（高 16，垂直居中），图标用 `Accent`，名称字重 600 |
| 工具栏开关（检查器、传输面板） | `ActiveFill` | 加 1px `BorderStrong` 描边，图标用 `Text` |
| 检查器标签、传输筛选 | 无 | 2px `Accent` 下划线；当前项用 `Text`、字重 600，其余用 `TextMuted` |
| 开关 | 关闭时轨道 `ControlOff`，开启时 `Accent` | 白色圆钮，位置随状态变化 |
| 复选框 | 未选时 `Surface` 底、1.5px `BorderStrong` 边框；选中与部分选中时 `Accent` 填充 | 选中是 `AccentText` 对勾，部分选中是 `AccentText` 横线 |
| 表格选中行 | `Selection` | 对象表行首的复选框勾选；若有焦点行，焦点行另加 1px `Focus` 内描边 |
| 命令面板、下拉选项、菜单的"当前值"（当前主题、语言、账户、已打开的存储桶、选择框当前项） | 无填充 | `Accent` 对勾加字重 600 |
| 命令面板、下拉选项、菜单的"高亮"（键盘光标或鼠标悬停） | `SurfaceHover` | 无：高亮是临时的指向，不是状态；它与"当前值"是两件事，同一行可以同时有两者 |
| 打开着菜单的按钮（上传、账户切换器、`⋯`） | `SurfacePressed` | 菜单本身挂在按钮下方 |

悬停只改填充（`SurfaceHover`），不能与选中状态混淆。禁用状态用透明度 0.4，同时不响应悬停。浮层列表里键盘光标与鼠标悬停是同一种外观（见"浮层"）。

## 对比度（`cmd/pail-desktop/theme_test.go` 强制检查）

- 必要文字（正文、字段标签、表头、按钮文字）≥ 4.5:1：使用 `Text` 或 `TextMuted`。**字段标签使用 `TextMuted`、字重 500**，不用 `TextSubtle`，以免标签被看成占位符。
- `TextSubtle` 只用于占位符、计数、分隔符和次要时间，对比度 ≥ 3.5:1。
- 输入框与次要按钮的描边 `BorderStrong` ≥ 1.8:1；开关关闭时的轨道 ≥ 2:1。
- 状态填充 ≥ 1.17:1，并且必须同时有第二线索。
- 复选框的 `Accent` 填充落在已选行的 `Selection` 与悬停行的 `SurfaceHover` 上都 ≥ 3:1；对勾与横线用 `AccentText`，对 `Accent` ≥ 4.5:1。

## 滚动

- mygo 的滚动条浮在内容之上。凡是可滚动区域，**都必须给滚动条留出内边距槽**：内容右侧内边距 ≥ 滚动条宽度 + 6，并用 `ScrollbarInsets` 把滚动条放进这个槽里。滚动条不能盖住输入框、按钮或文字。
- 对话框结构：固定的标题、可滚动的正文、固定的底部按钮。正文可以滚动时，顶部和底部显示 1px `Border` 分隔线；对话框最大高度为窗口高度减 64。在最小窗口 960×600 下，所有控件必须都能操作。
- 列表和面板在最小窗口下不能出现水平溢出；长文本单行截断，并带 Tooltip。
- 例外：放大后的图片预览在固定大小的框里平移，滚动条浮在图片上，不留槽。框里只有图片，没有文字和控件。

## 布局与缩放

- **布局只用当前帧的尺寸。** 宽度由 `c.Size()` 减去已知的侧栏、检查器和分隔条宽度算出（`layout.go` 的 `layoutMetrics`，每帧在 `body` 里算一次），不读 `Element.Bounds()`：它返回上一帧的盒子，拖动缩放时会晚一帧。
- **宽度断点带 ±12 回滞**：工具栏文字（680）、路径栏紧凑（560）、对象表列（752 / 592，含 32px 复选框列）都只在宽度低于"阈值 - 12"时收起，高于"阈值 + 12"时才展开；档位由 `layoutState` 记住。新增断点必须走 `breakpoint`，不得直接比较宽度。
- 侧栏与检查器保持用户给定的宽度，不随窗口自动缩窄。最小窗口 960×600 下靠工具栏图标化、路径栏紧凑和对象表减列保证所有控件可操作。
- 分隔条（mygo `Split`）悬停用 `BorderStrong`、拖动用 `TextSubtle`，不用 `Accent`（超出强调色的五处用途）；经 `app.split` 给 `Split` 一份私有主题副本实现。
- 单行文本不要用 `Grow(n)`：它同时把 basis 设为 0，文本的最小内容宽度为 0，会被冻结成 0 宽，只剩省略号。要让标签占满剩余空间，把它放进 `Grow(1).MinWidth(0)` 的容器，文本自己用 `Shrink(1).MinWidth(0)`（参见 `kvedit.go`、`help.go`）。

## 浮层

所有浮在窗口之上的界面共用一套外观，实现在 `cmd/pail-desktop/overlay.go`，数值来自 `theme.go`。新增浮层必须经 `overlayPanel`，列表型浮层的行必须经 `listRow`，不得自行写圆角、阴影或高亮色。

**面板种类**（`overlayPanel(kind)`）：

| 种类 | 用于 | 圆角 | 底色 | 边缘 |
| --- | --- | --- | --- | --- |
| `overlayDialog` | 对话框、命令面板、存储桶设置 | `RadiusDialog` 10 | `Surface` | 亮色：阴影 `ShadowDialog`（0 12 32，约 18% 黑）；暗色：1px `BorderStrong` |
| `overlayPopover` | 下拉选项、菜单 | `RadiusPopover` 8 | `Surface` | 亮色：阴影 `ShadowPopover`（0 8 24，约 14% 黑）；暗色：1px `BorderStrong` |
| `overlayTip` | Toast | `RadiusPopover` 8 | `Inverse`，文字 `InverseText` | 亮暗都无描边：反色块本身足够醒目 |

- 暗色背景上阴影看不见，所以暗色的阴影 token 是透明的，面板改用 1px `BorderStrong` 描边；亮色不描边，只靠阴影。两种做法由 token 是否透明决定，视图里不判断主题。
- 只有一层面板，不嵌套边框；对话框内部的滚动、分隔线规则见"滚动"。
- Tooltip 取 `Inverse` / `InverseText` 的颜色（`applyTheme` 设置）。mygo v0.6.3 仍没有改写 `Element.Tooltip` 外观的钩子，它的圆角（5）和阴影仍由库内决定，是已知的例外。

**列表行**（`listRow`，命令面板、下拉选项与菜单共用）：

- 高 28（`listRowH`），左右内边距 8，圆角 6，子项间距 8；从左到右依次是：14px 图标（`TextMuted`）、标签（13px `Text`）、副文字（12px `TextMuted`）、键帽、对勾（14px `Accent`）、子菜单箭头（`chevron-right`，`TextMuted`）。
- **高亮**：键盘光标所在行与鼠标悬停所在行外观相同，都是 `SurfaceHover` 填充，像原生菜单一样；不用蓝色 `Selection`。鼠标移动时光标跟着鼠标，鼠标静止时键盘方向键夺回光标。
- **当前值**：`Accent` 对勾加字重 600（两种线索）。当前值与高亮互不影响，可以出现在同一行。
- **禁用**：透明度 0.4，不响应悬停，不可点击，键盘光标跳过。
- 命令面板：每行显示命令自己的图标；浏览时命令按分组排列，分组标题用 `sectionLabel`，"此处不可用"也是一个分组标题；有搜索词时跨分组排序，分组名作为副文字显示在行内。
- 选项文字单行截断，不换行。

**键帽**（`keycap`）：高 20，左右内边距 4，圆角 `RadiusKeycap` 4，1px `Border` 描边，12px `TextSubtle`；一个按键一个键帽（`Ctrl`、`Shift`、`U` 是三个）。键帽落在高亮行上时，`Border` 与 `SurfaceHover` 太接近，描边升为 `BorderStrong`、文字升为 `TextMuted`。命令面板的 `Esc` 也是键帽。

**分隔线**（`listSeparator`）：1px `Border`，上下各留 4px 外边距，用于列表里的分组之间。

**菜单**（`ctxmenu.go`）：对象表与侧栏存储桶的右键菜单，以及上传、账户切换器、`⋯` 三个按钮的菜单。

- **平台分工**：Windows 与 Linux 在窗口内自绘，`overlayPopover` 加 `listRow`，与命令面板同一套行；macOS 保留系统菜单（平台约定），同一份描述交给 `ui.Menu`。调用处只写一次菜单描述（`menuBuilder`：`Item`、`Command`、`Separator`、`Submenu`，以及 `Icon`、`Checked`、`Disabled`、`Shortcut`），不判断平台。首尾和连续的分隔线自动去掉。
- **外观**：宽 200–320，内边距 4；命令项显示命令表里的图标和第一个快捷键（键帽）；同一层只要有一项有图标，其余项留出图标位，文字对齐。当前值是 `Accent` 对勾加字重 600，禁用是透明度 0.4、不响应悬停、键盘跳过。分隔线用 `listSeparator`。打开着菜单的按钮用 `SurfacePressed` 填充。
- **位置**：右键菜单的左上角落在指针处；放不下时翻到指针的另一侧（向上或向左），两侧都放不下时沿该方向移进窗口，离窗口边 4。按钮菜单挂在按钮下方、左对齐，放不下时改为右对齐或翻到上方（mygo `AttachTo`）。比窗口高时面板高度取窗口高度减 8，行在面板内滚动，滚动条放进右侧槽（见"滚动"）。子菜单贴在所在行的右侧、首行对齐，右侧放不下时翻到左侧。
- **打开**：右键（Windows 在松开右键时，Linux 在按下右键时，沿用 mygo 的判断）；焦点在对象表或存储桶上时按 `Shift+F10` 或菜单键，菜单出现在当前行下方并高亮第一项。按钮菜单在单击、`Enter`、`Space` 或 `↓` 时打开。同一时间只有一个菜单。
- **键盘**：`↑` `↓` 循环移动并跳过分隔线和禁用项；`Home` `End`；`Enter` `Space` 执行；`→` 或 `Enter` 打开子菜单并高亮其第一项，`←` 返回；`Esc` 先关子菜单，再关菜单；按字母或数字跳到下一个以它开头的项。键盘与鼠标共用同一种高亮，规则同"列表行"。
- **鼠标**：鼠标移动到哪一行就高亮哪一行；停在有子菜单的行上 150ms 后打开子菜单，停在别的行上 150ms 后关闭已打开的子菜单；单击子菜单行立即打开。
- **关闭**：执行一项时整条菜单链先关闭，动作在下一帧运行，所以动作打开的对话框能拿到焦点；`Esc`、在菜单外按下（左键或右键）、窗口尺寸变化、窗口失去焦点都会关闭菜单。菜单外的按下只关闭菜单，不会传给下面的控件（与 Windows 系统菜单一致）。关闭后焦点回到打开前的控件。
- **无障碍**：面板是 `RoleMenu`，名称是按钮的名字或"对象操作""存储桶 X 的操作"；各项是 `RoleMenuItem`，可勾选的是 `RoleMenuItemCheckBox` 并报告勾选状态，子菜单项报告展开状态，禁用项报告禁用；焦点留在根面板上，用 `ActiveDescendant` 指向当前高亮项。菜单层是模态的：窗口快捷键暂停，读屏只看到菜单。
- **限制**：自绘菜单不能超出窗口边界；文本输入框与可选文字的编辑菜单（剪切、复制、粘贴等）仍是 mygo 提供的系统菜单。

**Toast**：窗口底部居中，`overlayTip`，内边距 8 / 16，13px 文字，动作按钮 13px / 600，悬停时用 `InverseText` 14% 透明度的填充。出入场见"动效"。

## 动效

动效只说明状态从哪里来、到哪里去：快、轻、可以关闭。所有时长、曲线和弹簧都定义在 `cmd/pail-desktop/motion.go`，视图里不写裸数字。

**令牌**：

| 名称 | 数值 | 用途 |
| --- | --- | --- |
| `durFast` / `colorAnim` | 120ms，标准曲线 | 悬停与按下时填充、描边颜色的淡变（`hoverFade`） |
| `durStandard` / `fadeAnim` | 200ms，标准曲线 | 遮罩淡入、内容淡入、进度条宽度、"已保存"淡入、开关轨道颜色、复选框对勾、选择条高度 |
| `durSlow` / `panelAnim` | 260ms，标准曲线 | 传输面板展开与折叠 |
| `durExit` / `exitAnim` | 120ms，标准曲线 | 所有浮层与对话框的退出：只淡出（对话框另缩到 0.98），不带弹性 |
| `overlaySpring` | 弹簧 `Duration 240ms`、`Bounce 0.18` | 对话框、命令面板、下拉、菜单、子菜单、Toast 的入场 |
| `slideSpring` | 弹簧 `Duration 200ms`、`Bounce 0.12` | 指示线与指示条的滑动、开关圆钮 |

标准曲线是 `CubicBezier(0.2, 0, 0, 1)`（起步快、落地长）。弹簧的过冲很小：对话框入场的缩放过冲不到 0.1%。

**用在哪里**：

- **颜色**：所有按钮（ghost、次要、主要、危险、图标按钮、开关按钮）、侧栏项、分段控件、面板与菜单的行（`listRow`）、存储桶设置导航、传输行、版本行、复选框，悬停、按下和选中的填充与描边都淡变 120ms。
- **对话框与命令面板**（`modalLayer`）：遮罩淡入 200ms；卡片从 `Scale 0.94`、下移 6、透明，以 `overlaySpring` 进入；关闭时卡片淡出并缩到 0.98，遮罩淡出，都是 120ms。
- **下拉与菜单**：面板从 `Scale 0.94`、透明，以 `overlaySpring` 从锚点一侧长出（`TransformOrigin` 取锚点所在的角）：挂在下方的从上方 6 落下，翻到上方的从下方 6 升起；子菜单从父菜单一侧横移 6 滑出（翻到左侧时从右侧）。菜单关闭时，它最后一帧的样子作为"残影"淡出 120ms（`menumotion.go`）。
- **指示**：检查器标签与传输筛选的 2px 下划线、侧栏和存储桶设置导航的选中指示条，以 `slideSpring` 从上一个位置滑到新位置（mygo `Transition.Match`）；开关圆钮以 `slideSpring` 移动，轨道颜色淡变。
- **传输面板**：用按钮、工具栏开关、命令面板或新任务打开与关闭时，高度在标题栏与设定高度之间过渡 260ms；拖动分隔条时高度跟手，不加过渡。
- **复选框**：对象表行首复选框出现与隐藏时只淡变透明度 120ms，列宽不变；勾选时填充淡变 120ms，对勾或横线从 0.85 缩放到 1，用时 200ms。
- **选择条**：出现与收起时高度在 0 与 36 之间过渡 200ms，内容同时淡入或淡出；表格只变矮，已显示的行不移动。
- **检查器**：用户打开时内容淡入 200ms；宽度与位置不动画（宽度属于用户拖动的分隔条）。
- **进度条**：填充宽度以 200ms 追向新进度，失败时颜色淡变为 `Danger`。
- **计数**：状态栏的项目数与选中数、传输标题栏的摘要、传输筛选的计数，数字变化时逐位滚动（`ContentTransition{Numeric}`）。
- **"已保存"**：淡入 200ms，到时淡出 120ms。
- **Toast**：从下方 8 升起并淡入（`overlaySpring`），离开时淡出 120ms。

**禁止动画的地方**：

- **窗口缩放**：缩放引起的布局变化一律立即到位（mygo 不对缩放做过渡；应用里由缩放引起的显示变化，如检查器因窗口变宽重新出现，也不淡入）。
- **对象表**：虚拟化的行、行的出现与消失、滚动，应用都不加动画。滚动进视野的行直接显示复选框的最终状态，不淡入。框选矩形紧跟指针，出现和消失都不加动画。鼠标滚轮每一格在约 150ms 内缓出滚过（mygo v0.6.0 自带，与浏览器一致，触控板不受影响），这是库的滚动行为，不是应用动画。
- **装饰性循环**：不做呼吸、脉动等循环动画；加载指示沿用 mygo 的 `Spinner`。
- **Tooltip**：mygo v0.6.3 仍没有改写 Tooltip 的钩子，沿用库内行为，不加入场动画。

**交互不等动画**：入场中的对话框与菜单立即响应点击和键盘；正在退出的对话框与菜单是不可交互的残影，不拿焦点、不挡指针，下面的界面立即可用。动画结束后窗口不再请求新帧。

**减少动态效果**：系统开启"减少动态效果"时，位移、缩放、滑动、高度变化和滚轮滚动一律直接到位，只保留颜色与透明度的淡变（mygo 的默认行为），视图不需要另作判断。

**实现约束（mygo v0.5.5 起，v0.6.3 仍然如此）**：`Transition` 的 `Enter` 只在父元素上一帧已存在时播放；浮层层会在过渡之后重新布局，过渡对浮层内元素位置的改动会被覆盖。因此浮层的入场用 `AnimatePose`（绘制时生效的姿态，`enterPose`），退出用 `Transition` 的 `Exit`。

## 窗口外观

- **标题栏与应用融为一体**：所有平台都用 `TitleBarStyle: hidden`（macOS 用 `hiddenInset`），并设置 `TitleBarHeight: 44`，让系统窗口按钮与 44px 的工具栏同高。
  - 侧栏从窗口顶边开始，顶部 44px 是账户切换器。macOS 上它左侧让出红绿灯的位置（`c.TitleBar().Left`）。
  - 右侧主区顶部是一条横贯主区的 44px 工具栏，检查器在它下方。工具栏右侧让出系统按钮的位置（`c.TitleBar().Right`）。
  - 工具栏和账户切换器里的空白区域可以拖动窗口，双击可以最大化。
- **外观同步**：应用主题（跟随系统 / 亮 / 暗）同时设置 `mygo.Theme.SetSource`，让系统按钮、原生对话框，以及 macOS 上的系统菜单与应用一致；Windows 与 Linux 的菜单在窗口内自绘，直接用应用主题（见"浮层"的"菜单"）。窗口 `BackgroundColor` 使用 `light-dark(...)`，避免启动时闪色。
- **不用传统菜单栏**：Windows 与 Linux 不调用 `App.SetMenu`。macOS 保留系统菜单栏（这是平台约定），只放标准项和命令表。
  - 所有命令通过三个入口找到：
    1. 工具栏上的按钮；
    2. 右键菜单（外观与行为见"浮层"的"菜单"）；
    3. **命令面板**（`Ctrl/⌘+K`，也可用 `Ctrl/⌘+Shift+P`）：一个搜索框，列出命令表里的全部命令，每行显示图标、快捷键（键帽）和当前是否可用，支持中英文关键字；外观见"浮层"。
  - 工具栏最右侧（系统按钮左边）有一个 `⋯` 菜单按钮，分组列出：命令面板、设置、主题、语言、键盘快捷键、文档、关于 Pail、退出。
- "关于"对话框：图标、版本、许可证与第三方声明（Lucide ISC、Inter OFL），以及项目链接。

  | Sync | 同步 |
  | Conflict | 冲突 |
  | Endpoint | 端点 |
  | Region | 区域 |
  | Path-style | 路径样式 |
  | Access key | 访问密钥 |
  | Secret key | 私有密钥 |

- **"?" 说明图标**：所有含义不直观的配置项，在标签右侧放一个 14px 的 `circle-help` 图标（颜色 `TextSubtle`，悬停时 `TextMuted`），悬停或获得焦点时显示 Tooltip。

## 组件

### 侧栏

- 顶部是账户切换器，高 44：
  - 左侧 24px 圆角方块，`ActiveFill` 底色，内含账户名首字母，12px、字重 600；
  - 中间账户名 13px / 500，下一行 region，11px `TextSubtle`；
  - 右侧 chevron 图标，`TextSubtle`。
  - 整体是一个可点击区域，悬停时 `SurfaceHover`。
  - region 只出现在账户名下一行，不在别处重复。
- 分组标签（BUCKETS、TOOLS）用 `sectionLabel`，左右内边距 16，上 16、下 6。数量跟在标签后，用 `TextSubtle`。
- 列表项：
  - 高 28，左右外边距 8，内边距 8，圆角 6；
  - 14px 图标用 `TextMuted`，名称 13px 用 `Text`，region 11px 用 `TextSubtle` 靠右；
  - 悬停 `SurfaceHover`；
  - 选中项用 `ActiveFill`，名称字重 500，图标换成 `Accent`。
- 桶筛选框高 28：`Surface` 底色、1px `BorderStrong`、圆角 6，占位文字用 `TextSubtle`，左右外边距 12。
- TOOLS 分组贴底；与 BUCKETS 之间是弹性空白，不用分隔色块。

### 工具栏（高 44，`Background`，底部 1px `Border`）

- 按钮一律 ghost 风格：无底色无边框，高 28，左右内边距 8，图标 14px 用 `TextMuted`，标签 13px 用 `Text`；悬停 `SurfaceHover`，按下 `SurfacePressed`；禁用时整体透明度 0.4。
- 分组之间用 16px 高的竖线 `vline`，左右各留 6。
- 右侧检查器、传输面板两个开关：仅图标；打开时用 `ActiveFill`，图标用 `Text`。

### 路径栏（高 40）

- 面包屑：
  - 前面的段 13px，用 `TextMuted`，悬停变 `Text`；
  - 最后一段用 `Text`、字重 600；
  - 分隔符是 chevron-right 12px，`TextSubtle`；
  - 桶段前放 14px 桶图标。
- 右侧搜索框宽 240，样式同桶筛选框。

### 对象表

- 背景 `Background`，没有外框。
- 表头高 28：12px、字重 500、`TextMuted`，无底色，下方 1px `Border`。可排序列的箭头用 `TextSubtle`。
- 行高 30，行与行之间不画分隔线。悬停 `SurfaceHover`，选中 `Selection`，选中行文字保持 `Text`。
- 复选框列：
  - 名称列之前固定一列，宽 32，不能拖动或改宽；复选框 16px，水平居中，外观见"状态"。
  - 行内复选框只在悬停行、已选行上显示；选中两项及以上（选择条出现）时，所有行都显示。其余行的复选框透明，但列宽保留，所以名称列不会左右跳动。
  - 单击复选框切换这一行，其他行的选择不变（同 `Ctrl/⌘+单击`）；`Shift+单击` 复选框从上一次的起点选到这一行。单击行的其他位置仍是单选。
  - 行内复选框不接收键盘焦点，焦点留在表格上；读屏看到的是复选框，名称是"选择 <名称>"，勾选状态与行的选中一致。键盘用 `Ctrl+Space`（Windows、Linux）切换当前行。
- 表头全选：复选框列的表头是三态复选框，始终显示。
  - 状态按当前可见的行算（搜索框筛掉的行不算）：一行未选是未选，全部选中是选中，其余是部分选中。
  - 单击时，未选或部分选中会选中全部可见行，选中会清除选择，与 `Ctrl/⌘+A` 一致。名称是"全选"，Tooltip 显示 `Ctrl/⌘+A`。
  - 列表还在加载后续页时也可以点，只选已加载的行；选择条会注明列表仍在加载。
- 拖动选择：
  - 从复选框列按下拖动是刷选：从按下的行到指针所在的行都加入选择，原有选择保留，不会取消已选的行。不画矩形，行直接显示勾选。
  - 从最后一行下方的空白处按下拖动是框选：拉出矩形，矩形纵向碰到的行成为选择（横向位置不影响）；按住 `Ctrl/⌘` 时加入原有选择。矩形用 `Selection` 50% 透明度填充，1px `Accent` 描边，圆角 2。
  - 名称列和数据列保持原样：单击选择，拖动行移动到文件夹，双击打开。
  - 移动 4px 后才算拖动；不到 4px 时按单击处理：复选框列切换这一行，空白处清除选择（按住 `Ctrl/⌘` 时不变）。
  - 拖动时选择、状态栏和选择条即时更新；`Esc` 放弃这次拖动，回到按下前的选择；松开即结束。指针在列表上下边缘 32px 以内或拖出列表时自动滚动，越往外越快，到头停止。
  - 重命名时、右键或中键按下时、按在滚动条槽上时不开始拖动选择。
- 名称列：16px 图标后接 13px `Text`。文件夹图标用 `FolderIcon`，文件图标用 `TextSubtle`。
- 大小、类型、修改时间、存储类别四列用 12px `TextMuted`；大小右对齐。
- 焦点在表格上、且没有在重命名时，`Esc` 清除选择。
- 拖放上传：表格区域整体 1.5px `Accent` 描边、圆角 8，填充 `Selection` 的 50% 透明度，中央是 upload 图标加"Drop to upload to <prefix>"。
- 空状态：垂直居中，32px 图标用 `TextSubtle`，标题 13px / 500，副标题 12px `TextMuted`。

### 选择条（高 36，`Background`，顶部 1px `Border`）

- 选中两项及以上时出现在对象表下方、传输面板上方；选择清空或只剩一项时收起。只选一项时，工具栏和检查器已经覆盖它的操作，不出现选择条，单击行也不会让表格高度变化。
- 左侧是汇总：
  - "已选 12 项 · 3.4 MB"，13px / 500 `Text`，数字逐位滚动；大小只计对象，不计文件夹；
  - 含文件夹时接"· 含 2 个文件夹"，12px `TextMuted`；
  - 列表还在加载时接"· 列表仍在加载"，12px `TextSubtle`。
- 中间是 ghost 按钮：下载、复制、剪切、删除，以及 `⋯`（打开与右键菜单相同的菜单）。按钮来自命令表，是否可用、是否显示与工具栏一致；当前后端不支持的命令不显示。
- 右侧是 ghost 按钮"取消选择"，带 `x` 图标。
- 选择条里没有实底按钮。对象表减列时，所有按钮（包括"取消选择"）只显示图标，名称放 Tooltip；汇总放不下时用省略号截断，按钮不缩小。

### 检查器（宽 320，`Background`，左侧 1px `Border`）

- 顶部标签条高 40：
  - 图标按钮 28×28，未激活时图标 `TextMuted`；
  - 激活项的图标与文字都用 `Text`，正下方是 2px `Accent` 指示线（宽同按钮，圆角 1）；
  - 不使用填充胶囊。
- 头部，内边距 16：
  - 40px 方形图标块，`Sidebar` 底、圆角 8；
  - 名称 14px / 600 单行省略，副标题 12px `TextMuted`。
- 属性列表：
  - 不画格子表，每行为标签（12px `TextSubtle`，宽 96）加值（13px `Text`），行距 8；
  - 分组之间留 16 间距，加 hairline 和分组标签；
  - 长值（ETag、Key、URI、URL）独占一行：标签单独一行，值用 12px 等宽字体可换行，右上角放复制按钮 `iconButton`。
- 图片预览：
  - 适配检查器的内容宽度，圆角 `RadiusControl`；下方一行是像素尺寸与当前显示比例（12px `TextSubtle`），右侧是缩小、放大两个 `iconButton`，到达适配宽度或 8 倍时对应按钮禁用。
  - 捏合触控板或按住 Ctrl 滚动滚轮，在指针处缩放；按钮绕框的中心缩放。框保持适配时的大小，缩放不推动下方内容。
  - 放大后拖动（抓手光标）、滚轮或触控板平移；双击回到适配宽度。换一个对象时回到适配宽度。

### 传输面板

- 默认高 168：标题栏 32 加 4 行。最小 96，可折叠。背景 `Background`，顶部 1px `Border`。
- 标题栏：
  - "Transfers" 12px / 600；
  - 筛选项是文字标签"Active 3 / Completed 1 / Failed 1"，12px `TextMuted`；当前项用 `Text`，下方 2px `Accent` 指示线；
  - 右侧是"Clear finished"文字按钮和折叠按钮。
- 行高 32，从左到右依次为：
  - 方向图标，14px `TextMuted`；
  - 名称，13px 弹性宽度；
  - 进度条：固定宽 160、高 4、圆角 2，轨道 `Border`，填充 `Accent`，失败时整条为 `Danger`；
  - 字节数：右对齐宽 128，12px `TextMuted`，例如"1.6 GB of 2.4 GB"；
  - 速度与剩余时间：宽 112，12px `TextSubtle`；
  - 取消或重试按钮 `iconButton`。
- 状态图标：完成用 check `Success`，失败用 alert-circle `Danger`，排队中显示"Queued"，`TextSubtle`。

- 卡片：`overlayDialog`（`Surface` 底，圆角 `RadiusDialog`，亮色阴影 `ShadowDialog`、暗色 1px `BorderStrong`，见"浮层"），宽 440，内边距 20。只有一层卡片，不要嵌套边框。存储桶设置对话框用同一个外框（`dialogFrame`）和同样的标题行、底部行，宽 760、高固定，列表和表单各自滚动，分隔线只在其中之一可滚动时显示。

### 按钮总则

只有三种按钮：ghost、次要（描边）、主要或危险（实底）。整个窗口同一时间最多只有一个实底按钮。
